# 河洛数字博物馆简历竞争力锐评计划

## 目标

以全栈工程师岗位为标准，同时审查线上 PocketBay 站点与本地仓库，产出可验证的项目评分、核心流程验收、风险清单和简历表达。只记录已验证事实，不虚构指标。

## 关联范围

- 产品：公开浏览、搜索、3D 展厅、登录、预约、商城/模拟支付、个人中心、管理员后台。
- 工程：Vue 3/TypeScript/Vite、Spring Boot/Java 17、MySQL/Flyway、Security/JWT、Docker Compose、Three.js。
- 证据：线上页面、仓库文档/代码、类型检查、单元测试、构建、后端测试、容器配置和核心浏览器流程。

## 步骤

1. 线上首屏与主路径检查。
2. 前后端、权限、状态机、数据迁移和部署静态审查。
3. 运行最小工程质量门禁，并记录未运行/失败项目。
4. 形成 100 分评分卡与 P0/P1/P2 整改路线。
5. 更新项目状态、需求追踪和锐评报告；不修改业务代码、不提交 Git。

## 验收标准

- 报告区分已验证、待验证和不应写入简历的事实。
- 评分有证据来源，不用主观视觉评价替代工程证据。
- 核心流程覆盖内容、3D、认证、预约、订单、后台和越权。
- 简历描述不夸大真实支付、真实历史文物或生产容量。

## 风险

- 当前工作树存在大量既有未提交改动，本任务不得重置或混入代码修复。
- 线上 PocketBay 可能休眠或受平台反馈组件影响；线上结果需记录实际状态。
- 真实移动设备、慢网、系统强制颜色和生产级容量不应被本轮浏览器/本机结果替代。
