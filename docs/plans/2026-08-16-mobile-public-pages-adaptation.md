# 公开页面移动端排版与点云视觉适配

## 目标

修复用户在 `412×915` 移动视口标注的首页标题遮挡、Explore 首屏卡片笨重、商城商品卡叠压，以及 3D 展项移动点云过黑过粗问题；同时保证桌面布局仍清晰、可扫描。

## 关联需求

- `F-01`、`F-02`、`F-03`：公开内容浏览、检索与中英文呈现。
- `F-05`：3D 展项查看与实体/点云交互。
- `F-09`：文创商品浏览与分类。
- `F-12`、`F-14`：公开页面导航、内容呈现与响应式体验。
- `N-03`、`N-06`：兼容性、可访问性与性能。

## 影响范围

- 首页策展卡片的移动端排版。
- Explore 馆藏导览首屏的移动端层级、装饰密度和搜索区尺寸。
- 商城首屏、分类栏和商品卡在移动端及桌面端的布局。
- 3D Viewer 点云的移动端点数、点径、透明度和色彩层次。
- 上述样式与点云参数的专项测试。

不修改 API、路由、鉴权、商品/购物车/模拟支付业务、预约状态机、3D 模型来源、相机预设、实体/点云切换和资源释放流程。

## 设计方向

- 首页：序号回到信息流中，图片与文字不再共享容易重叠的定位层；卡片像紧凑的馆藏目录条目。
- Explore：保留河洛山水识别，但移动端只保留一层背景意象和一个搜索任务区，删除同心环等无助于操作的装饰。
- 商城：商品图承担主视觉，名称、库存、价格和按钮进入稳定信息区；移动端单列，桌面端三列，不再依靠绝对定位拼贴。
- 点云：移动端使用更细、更疏、更通透的深玉与古铜颗粒，保留鼎的轮廓和交互反馈。

## 实施步骤

1. 新建公开页面响应式收口样式，并在 Home、Explore、Shop 的现有最终样式后加载。
2. 调整首页卡片在 `760px` 以下的网格、媒体尺寸、序号位置、标题换行与正文行高。
3. 调整 Explore 在 `760px` 以下的首屏高度、留白、背景装饰与搜索卡层级。
4. 将商城商品区统一为桌面三列、平板两列、移动单列的正常文档流，分类栏使用可控横向滚动。
5. 降低移动点云预算、点径和不透明度，调整 fragment 边缘与色彩，保持桌面质量级别不变。
6. 补充专项合同测试，运行前端测试、类型检查、生产构建和响应式门禁。
7. 重建正式 Docker 前端，在 `412×915`、`390×844`、`1440×900` 下检查中英文、双主题、无横向溢出、无文字遮挡和控制台错误；3D 额外检查 Canvas 非空及模式切换。

## 验收标准

- 首页三张策展卡标题、序号、图片与说明互不遮挡，最长英文标题也能自然换行。
- Explore 移动首屏不再接近整屏的厚重嵌套卡片，搜索控件保持至少 `44px` 可点击高度。
- 商城商品卡在移动与桌面都不叠压、不漂浮，图片比例稳定，分类可滚动且无页面横向溢出。
- 移动点云不再呈现密集黑色圆片，鼎身、双耳和三足轮廓仍可辨识。
- 相关测试、类型检查、构建和 `qa:pointer-pages` 通过；正式 Docker 页面 HTTP 与健康接口正常。

## 风险

- 项目存在多层历史 CSS，必须使用页面级作用域并通过正式页面计算样式确认最终级联。
- 降低移动点数可能影响局部纹样辨识，需结合真实 Canvas 截图与非空像素检查调整。
- 当前工作区包含大量用户未提交改动，本任务只追加最小范围文件，不清理、不重置、不提交。
