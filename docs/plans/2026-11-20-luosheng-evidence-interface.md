# 洛笙资料库与展签精修

关联 LS-02、LS-03、LS-04、LS-06。以青铜鼎为试点，扩充本机模型预览资料，同时优化深浅色展签。

- 将三条数字模型观察和四条参考馆藏资料放入独立的本机预览资料库。参考资料包含馆藏登记、断代、尺寸与材质、纹饰解读。依据为[克利夫兰艺术博物馆条目](https://www.clevelandart.org/art/1962.281)和[公开 API](https://openaccess-api.clevelandart.org/api/artworks/138016)。
- 正式卡包沿用签核流程。答复须将馆方断代和解读归属于编号 1962.281 的参考藏品。公开记录未填写出土地。
- 展签使用月白、青墨、铜和玉色，延续站内标题与正文字体。展签的应答区显示当前看点和可点开的图版或馆藏记录，配合细刻线与低频等待动画。
- 验收覆盖深浅色、手机及桌面尺寸、资料来源、图版动作和缺证。实际模型答复需抽查是否混淆数字模型与参考藏品。

## 验证结果

### 深色精修与动态导览入口

关联 LS-01、LS-06。延续站内的暖色暗底，展签采用暖石墨灰、低饱和青灰、哑光铜、灰玉和象牙白。青灰用于问答与回答区域，铜色聚焦主操作，灰玉标记问答状态。沿用现有宋体标题和黑体正文。全站浮动入口在两种主题下使用罗盘光弧和短促的扫光，支持减少动态效果。改动涉及共享配色、展签、入口组件及现有验收脚本。检查键盘回焦、动态效果开关、文字对比和窄屏入口位置。

Chrome 本机验证 390px 深浅色及 1440px 深色，覆盖两种动效偏好、键盘打开与回焦、窄屏底栏间距及实际计算色。深色入口与回答区的文字对比分别为 12.87:1 和 11.57:1。前端 506 项单测、类型检查、生产构建和资源预算通过。真机和部署待验。

### 展签双主题与字形精修

统一外框、问答面板、输入、推荐问题、回答、看点和图版的主题颜色。浅色用暖白与深玉，深色用墨绿与暖铜。宋体用于展签标题，中文黑体用于长文、输入和操作。实时回答的馆藏出处改为静态文字。验收检查两种主题的实际计算色、文字对比和出处呈现。

此前的资料库回归在 390px 深色和 1440px 浅色通过，后端 70 项定向测试通过。此次从首页导览进入青铜鼎，重新验证两个尺寸和主题下的 DeepSeek Flash 回复、看点接续、图版和缺证提示。两组在模型回复中均显示馆藏编号且无对应跳转，并验收了问答面板和输入框的实际计算色。前端 506 项单测、类型检查、生产构建和预算通过。正式发布签核和真机读屏待验。
