# 浅色 A 方案深玉压边 + 古铜嵌线组件重建计划

## 1. 目标

用户否定上一版 A+C 混合结果，重新确认采用效果图 A 的组件材质。目标不是复制效果图中的页面内容，而是把其“器物化边缘结构”落到现有真实 DOM：米白石材面、深玉压边、古铜嵌线、硬朗分层阴影和清晰的默认/悬停/聚焦/按下/禁用状态。

## 2. 参考标准

- 用户参考图：`docs/design/audit/2026-08-14-light-ui-a-jade-bronze-material/reference-a-user.png`
- 原始临时路径：`C:\Users\Jie\AppData\Local\Temp\codex-clipboard-0e6cca57-d1b4-484c-b875-2a6fac549652.png`
- 参考图用途：设计审计与材质合同，不作为生产图片，不把图中的文字、示例文物、按钮或卡片截图直接放入网页。
- 关键视觉：暖米白/石材内容面；深玉色厚底压边；单条古铜线；近直角、轻微切角；短而明确的接触阴影；深玉主按钮、米白次按钮；活动态以深玉填充、古铜线收边。

## 3. 范围

- 覆盖：浅色模式下的卡片、内容面板、搜索框、主/次按钮、复选框、分段筛选、日期/时段选择、状态徽章、原生输入/选择框、账户/预约/商城/后台工作区。
- 保留：现有 Vue 组件 props、事件、表单校验、API、路由、鉴权、搜索/筛选/分页、预约/订单状态机、模拟支付、SKU 内容和 Three.js 生命周期。
- 不做：新增业务逻辑、改变页面信息架构、替换真实馆藏/商城媒体、修改深色主题、把用户参考图作为运行时资源。

## 4. 实施要点

1. 将后置浅色材质层从 A+C 混合令牌改为 A-only 令牌：石材面、深玉压边、古铜嵌线、边缘高光、接触阴影、凹槽阴影。
2. 卡片采用“面层 + 1px 古铜/石材分隔线 + 深玉底轨”的结构，避免上一版连续软边和过度圆润。
3. 按钮采用实体薄片结构：主按钮深玉面/古铜细线/深玉底层，次按钮米白面/古铜细线/深玉底层；状态通过位移、阴影和填充变化表达。
4. 搜索框使用内陷石材槽、左侧检索标记、独立深玉提交按钮；复选框与分段控件使用同一实体边缘合同。
5. 保留键盘焦点、减少动态、减少透明度、高对比度、强制颜色和移动端 44px 触控门禁。

## 5. 验收标准

- 浅色真实页面不再呈现“白卡 + 轻薄线框”或 A+C 的软釉面混合感；卡片和按钮能明确看到深玉压边与古铜细线。
- `/`、`/explore`、`/exhibits`、`/appointment`、`/shop`、`/login`、`/profile` 的共享控件材质统一，深色页面不受影响。
- 搜索、筛选、日期/时段选择、预约表单、商城加购和登录入口行为不改变。
- 桌面与 `390×844` 移动视口无横向溢出、无控件裁切，键盘焦点可见。
- 通过相关 Vitest、类型检查、生产构建、页面映射、性能体积、Docker HTTP/health 回归，并归档 A 方案实页截图。

## 6. 风险与未验证项

- 参考图的真实纸张/金属/玉石纹理不能直接通过 CSS 完全复制，本轮使用无外部纹理依赖的颜色、边轨、伪元素和阴影重建结构。
- 真实手机、触控笔、Windows 强制颜色、真实慢网、后台管理员 CRUD 和深色实体设备仍需现场补验。
- 本轮不执行 Git commit，保留工作区中其他任务的 dirty changes。
