# 圆形发光点波鼠标动效

## 目标

根据用户提供的参考图，将当前“数字文物扫描场”收敛为更简约的圆形发光点波：规则点阵作为安静的数字底层，鼠标仅呈现一个高亮核心、一圈精细光环和局部点波响应；删除网格连线、切向扭曲和扫描刻度。

## 关联需求

- F-01 / F-02 / F-03 / F-05 / F-09：公开前台品牌展示与鼠标交互。
- N-03 / N-06：媒体偏好、混合输入、性能和资源释放。

## 设计原则

1. **一个视觉焦点**：鼠标中心只有一枚月白青玉发光点和一圈细环，不堆叠仪表盘式装饰。
2. **规则而非变形**：点阵保持秩序，只在局部做轻微径向位移、亮度和尺度波动，不连接成网。
3. **科技感来自光学层次**：使用短半径柔光、精细描边和速度驱动的轻量扩散，不使用大面积霓虹。
4. **品牌适配**：图片背景使用冷月白青玉光，纸面背景使用墨玉光，少量古铜节点仅承担节奏。
5. **渐进增强**：保留共享 RAF、静止停帧、离开回弹、低帧降级、减少动态、高对比度、pen/touch 和减少透明度契约。

## 实施步骤

1. 调整点阵密度和大节点分布，使底层更接近参考图的均匀数字采样场。
2. 将环形扫描波改为局部圆形点波，移除切向位移和相邻连线。
3. 重绘鼠标核心：柔光晕、单细环、白玉核心与极淡外沿。
4. 更新组件属性和几何测试，加入无切向扭曲、位移受限和状态回收断言。
5. 运行测试、类型检查、构建、体积、性能和多尺寸页面映射。
6. 无缓存重建 Docker，在生产实页目视确认并检查控制台。
7. 更新文档并审查 diff，不自动提交。

## 验收标准

- 不再出现网格连线、扫描短弧、十字刻度或大范围形变。
- 鼠标中心为清晰但克制的圆形发光点，只有一圈主要光环。
- 周围点阵呈圆形亮度/尺度波，移动时平滑，停止后停帧，离开后复位。
- Windows 减少透明度下仍清晰可见；减少动态、高对比度、pen/touch 等既有降级不回归。
- 工程、性能、页面映射、Docker 与浏览器实页验证通过。

## 风险

- 首页背景明暗跨度较大，核心光不能只依赖半透明白色；需同时使用墨玉细环保证浅色区域可见。
- 发光模糊半径必须受控，避免高 DPR 与高刷新率下扩大绘制成本。
