# 全站深色模式实施记录

## 目标

为前台与后台增加可持久化的深色主题切换，继续复用 `data-glass="light|dark|compact"` 三层材质契约，使用低彩度通透墨绿色承载页面、表单和看板。

## 范围与约束

- 关联需求：F-14（前后台主题切换，新增视觉增强需求）。
- 影响文件：`frontend/src/stores/theme.ts`、`frontend/src/App.vue`、`frontend/src/components/AdminShell.vue`、`frontend/src/assets/main.css`、`frontend/index.html`、`frontend/src/components/ThreeExhibitViewer.vue`。
- 不修改 API、路由、权限、数据库、模型文件、点云 palette、粒子点数或切换状态机。
- 主题状态使用 `heluo.theme` 持久化，默认浅色；根节点同步 `data-theme` 和 `color-scheme`。

## 验收标准

- 前台导航和后台页头均可切换浅色/深色，刷新后主题保持。
- 首页、馆藏、详情、展厅、3D、预约、商城、登录、个人中心、后台内容和后台运营在深色下文字、输入、焦点和玻璃表面可读。
- 深色主题只新增主题变量覆盖；三层玻璃 canonical token 仍各定义一次。
- 点云颜色和点云扩散/切换动画不发生变化；3D 场景仅根据主题选择环境雾色。

- `pnpm typecheck`：通过。
- `pnpm exec vitest run src/stores/theme.spec.ts src/assets/glassMaterials.spec.ts`：通过（11 项）。
- `pnpm test`：通过（24 个测试文件、87 项）。
- `pnpm build`：通过；仅保留既有大分包提示。
- `git diff --check`：通过（仅有工作区既有换行提示）。
- Docker 前端镜像已重建并替换运行，`http://localhost:8088/` 返回 `200`。
- 浏览器回归：深色主题刷新保持；首页、馆藏、展厅、预约、商城、登录和 3D 展厅均为深墨玻璃且无横向溢出；`390×844` 移动端主题按钮、底部导航和 3D 渲染状态正常；控制台无错误。
- 修复一次 CSS 级联回归：深色三层材质令牌现在以与公共契约相同的 `#app` 锚点优先级覆盖浅色默认值，运行时计算值已确认分别落到深色 `light / dark / compact` 表面。
- 点云 palette、粒子颜色、点数、扩散动画和实体/点云状态机未修改；3D 仅根据主题切换环境雾色。
