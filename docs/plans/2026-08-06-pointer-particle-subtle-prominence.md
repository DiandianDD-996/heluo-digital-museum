# 鼠标粒子轻量显著度优化

## 目标

根据用户对正式页面的直接反馈，在不重做现有圆形发光点波、不增加粒子密度和运动幅度的前提下，小幅提高首页、馆藏、数字展厅和商城粒子的可见度、色彩鲜明度与局部光感，并将同一套交互接入预约主区域。

## 关联需求

- F-01 / F-02 / F-05 / F-06 / F-09：公开前台浏览、数字展项、预约与商城体验。
- N-03 / N-04 / N-06：响应式、性能降级与可维护性。

## 影响范围

- `frontend/src/components/PointerDotField.vue`：小幅提高三套 palette 的明度、饱和度和不透明度，仅为活跃粒子增加短距离 Canvas 光晕。
- `frontend/src/views/AppointmentView.vue`：在 `booking-main` 中复用现有 `PointerDotField`。
- `frontend/src/assets/pointerDotFieldMapping.spec.ts`：将预约加入允许的页面映射并锁定轻量光效边界。
- 项目状态和需求追踪。

不修改粒子数量、点阵间距、波场半径、位移、缩放、共享 RAF、鼠标双圆、业务表单、API、路由、Three.js 或输入降级规则。

## 实施步骤

1. 基础粒子透明度只提高约 `0.06–0.08`，活跃粒子提高约 `0.06–0.12`，青玉和鎏金向更清亮方向微调。
2. 首轮活跃粒子使用最大 `8px` 的短距离青玉/鎏金 Canvas 阴影；根据用户连续实页反馈逐档提高到最大 `12px`，减少透明度模式继续使用高对比实色且不绘制阴影。
3. 用户截图确认实际浏览器命中减少透明度模式后，不再把透明阴影的参数提升当作实页光效证明；为三套 palette 增加粒子内核高光，并为减少透明度下的活跃粒子增加不使用模糊的实体浅色光环。
4. （已回退）针对白色纸面占比高而增加的 opaque 高饱和外缘与明亮内核，因用户提供的截图要求恢复原视觉，现不再作为运行实现。
5. 预约主卡片挂载纸面 variant，内容层继续高于 Canvas，不改变日期、时段、表单和移动底栏。
6. 运行专项测试、全量前端测试、类型检查、构建、体积/性能/页面映射门禁。
7. 无缓存重建 Docker，在五个页面和 `390x844` 预约页实测，检查视觉、溢出和控制台。

## 验收标准

- 四个现有页面的粒子比当前版本稍明显，但仍退后于标题、图片和主操作。
- 指针附近可看见更清晰的青玉/鎏金亮点与短光晕，不出现大片霓虹或持续动画。
- 预约主区域具有同一粒子交互，所有日期、时段和表单控件仍可正常操作。
- 粗指针、减少动态、高对比度、强制颜色和性能降级行为不回归。
- 工程门禁、Docker 和生产浏览器验证通过。

## 风险

- 图片背景明暗跨度大，过强光晕会抢占器物主体；因此只增强活跃粒子，不给整张基础点阵增加模糊。
- 预约页控件密集，Canvas 必须保持 `pointer-events: none` 且内容层高于粒子层。

## 验证结果

- 实现：回退至截图对应的图片/纸面/减少透明度单层 palette；移除新增基础亮芯、opaque 活跃描边与白底双色外缘，保留原有青玉/鎏金点阵和最大 `11px / 12px` 短光晕。粒子数量、间距、波场半径、位移和缩放保持不变。预约 `booking-main` 继续复用同一 `PointerDotField`，Canvas 位于内容下方且 `pointer-events: none`。
- 工程：回退后专项 3 个测试文件 9 项、全量前端 23 个测试文件 84 项通过；`pnpm typecheck`、`pnpm build`、`git diff --check` 均通过。构建仍有既有 `@vueuse/core` PURE 注释提示和按 3D 路由懒加载的 Three.js 大 chunk，本轮未新增依赖。
- 体积与性能：第三次增强后 `pnpm perf:pointer-size` 通过，交互 JS 为 `16,585 B / 6,183 B gzip`，低于 `18 KB / 7 KB` 门禁；`pnpm perf:pointer` 的 16 项门禁全部通过，普通路由未加载 Three.js，后台停帧、低帧率降档、减少动态、减少透明度、高对比度、强制颜色、200% 缩放、混合触控笔和粗指针降级均保持有效。
- 页面映射：`pnpm qa:pointer-pages` 在首页、探索、数字展厅和商城的八档尺寸共 32 组通过；无横向溢出、控件裁切或阻塞事件，四页 Canvas 均非空并可在 full 档激活。
- Docker：回退版本使用 `--no-cache` 重建并替换前端容器，运行镜像为 `sha256:c54ebd4b4edc6021cf439d4193e94ae108876cd7f64367f3b3144738298852b5`；首页 HTTP `200`、容器内后端 health 为 `UP`，运行资源已确认不存在回退掉的亮芯/实体描边颜色与线宽指纹。
- 回退实页：生产首页为 `full / opaque`，Canvas 继续使用 `pointer-events: none`，页面 `scrollWidth === clientWidth`；显示的是截图对应的小尺寸单层点阵，而不是上一轮白底双色增强。
- 浏览器：在 `1465x898` 生产页面逐页检查 `/`、`/explore`、`/exhibits`、`/shop`、`/appointment`，五页各有且仅有一个粒子 Canvas，均可进入 `active`；第三次增强后青玉点、鎏金节点和指针附近中心亮点更鲜亮，但未扩散为大面积光斑，也未压过标题、器物或主操作，控制台无 warning/error。预约日期和时段仍可点击；`390x844` 下日期可切换、无横向溢出，Canvas 不接管事件。真实粗指针禁用由自动化门禁证明，本轮未重复实体手机手感测试。
