# 2026-08-06 第一阶段 Demo 全量复核与精修

## 目标

对河洛数字博物馆第一阶段 Demo 进行一次可复现的前后台质量复核；修复复现出的 UI 回归与测试同步问题，不改变 REST API、鉴权、预约、订单、支付或既有路由规则。

## 关联需求

- F-01 至 F-13：前台内容浏览、展项、预约、商城、身份与后台管理流程。
- N-01 至 N-06：响应式、可访问性、性能、加载/降级、测试和部署质量要求。

## 影响范围

- `frontend/src/views/ShopView.vue`：保持玻璃材质契约的稳定属性顺序，避免静态材质审计误报。
- `frontend/src/components/PointerDotField.spec.ts`：在响应式状态变更后等待 Vue DOM 刷新，避免测试遗漏真实状态并遗留动画订阅。
- 项目状态与需求追踪文档：记录本轮实际验证结果，不将未执行项标为完成。

## 步骤

1. 核对项目状态、需求追踪、前端设计契约、工作区改动与运行配置。
2. 执行前端类型检查、单测、构建、指针性能/页面映射审计，以及后端测试和 Docker 运行验证。
3. 修复可复现问题后，重复执行相关测试与浏览器尺寸回归。
4. 更新项目状态、需求追踪和本计划的验证结果，审查 Git diff；不提交。

## 验收标准

- 前端 `typecheck`、`test`、`build` 通过。
- 指针性能、触控目标和页面映射审计无阻断项。
- 后端测试通过；Docker 前端服务实际重建后可访问。
- 代表性前台与后台路由在桌面和窄屏下无关键横向溢出、空白切换或遮挡。
- 本轮发现的问题、未验证项与风险如实同步到状态和追踪文档。
