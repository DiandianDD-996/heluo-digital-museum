# 2026-08-16 预约票券双主题几何一致性修复计划

## 状态

- 本地实施与正式 Docker 页面验收完成，等待用户刷新后的最终目视确认。

## 目标

修复 `/appointment` 桌面预约票券在浅色/深色切换时的布局跳变。两种主题使用同一张票券画布比例、标题/路线/摘要锚点和英文控件尺寸；材质、颜色和深色 SVG 回退继续保留主题差异。

## 关联需求

- `F-06`：预约日期、时段、联系人信息、人数与提交行为保持不变。
- `F-12`：票券标题、路线站名和摘要继续支持中英文。
- `F-14`：深浅主题切换不改变核心票券结构和交互位置。
- `N-03/N-06`：保持桌面响应式、移动端 BottomSheet、辅助功能回退和可维护性。

## 基线问题

在 `1433 x 898` 英文页面中，同一宽度的票券实测为：浅色 `540 x 686.19px`，深色 `540 x 588.39px`。浅色使用固定比例画布与绝对定位，深色仍使用内容流布局，造成切换时标题、路线、摘要和联系人区整体跳动；深色英文站名、提示和人数步进器也比浅色更宽更大。

## 影响范围

- `frontend/src/assets/control-surface-polish.css`：为桌面深色票券补齐浅色票券的几何合同，保留深色材质令牌。
- `frontend/src/assets/ControlSurfacePolish.spec.ts`：增加深色票券比例、区域锚点和英文尺寸契约。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：记录实现、验证结果和未验证项。

## 验收标准

- 浅色与深色票券外框在同一桌面宽度下使用 `1049 / 1333` 比例，主题切换不再改变卡片高度。
- 标题、路线板和摘要区都使用相同的 `top/left/width/height` 百分比锚点。
- 英文三站标签、提示文字和人数步进器尺寸在两种主题下保持一致。
- 深色仍隐藏浅色 WebP 图层，使用深色 CSS/SVG 回退；浅色继续使用票券与路线 WebP 素材。
- `390 x 844` 移动端不挂载桌面票券，API、路由、预约表单、人数边界、状态机和 BottomSheet 不变。

## 风险与未验证项
