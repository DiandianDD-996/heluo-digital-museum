# 深色主题视觉优化

## 目标
统一深色模式的深墨、石墨明度层级，降低青绿色大面积使用，并减轻首页深色背景遮罩，保持与浅色首页一致的构图和信息层级。

## 影响范围
- `frontend/src/assets/tokens.css`：深色基础令牌。
- `frontend/src/assets/main.css`：首页深色遮罩。

## 验收标准
- 深色页面背景、分区、卡片、浮层存在可感知明度层级。
- 首页深色主视觉不再被多重近黑渐变压暗。
- 浅色主题、路由和业务逻辑不变。
- 类型检查、主题单测和生产构建通过。

## 风险
深色素材本身分辨率问题仍需后续重新生成高清母图；本次先修复 CSS 对素材的额外压暗。
