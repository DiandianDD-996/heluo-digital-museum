# 后台左侧导航玻璃材质对齐

## 目标

将后台左侧导航栏及其两张导航项卡片接入与前台深色毛玻璃卡片相同的语义材质令牌，删除后台专属的月白激活卡片配色，使后台仍保持工作台信息层级但在色相、边框、高光、阴影和减少透明度降级上与前台一致。侧栏底板作为页面壳层采用直角全幅布局，完整贴合桌面视口左侧与上下边界，不露出页面底色。

## 关联需求

- F-04 / F-07 / F-11 / F-13：后台内容与运营工作台。
- N-03 / N-06：响应式、可读性和设计系统可维护性。

## 实施范围

- `AdminShell.vue`：导航链接声明为共享 `dark` glass interactive 表面。
- `main.css`：激活和悬停态只引用现有 `--museum-glass-dark-*` 令牌，不新增后台私有颜色；侧栏底板覆盖共享卡片圆角和外侧边框，桌面只保留右侧分隔线，窄屏只保留下边分隔线。
- 玻璃材质契约测试、项目状态和需求追踪。

不改后台路由、权限、请求、表单、数据或工作区布局。

## 验收标准

- 左侧栏底板与导航项均复用前台深色毛玻璃的表面、边框、光泽和阴影语言。
- 桌面侧栏左上、左下均为直角并贴合视口，上、下、左侧无露白；侧栏保持贯穿视口高度。
- `900px` 以下侧栏转为顶部导航时保持全宽直角，只保留下边分隔线。
- 活动项可辨识，但不再显示独立的浅白后台卡片。
- 窄屏、减少透明度、高对比度和强制颜色模式仍由共享材质契约降级。
- 测试、类型、构建、Docker 与管理员实页验证通过。

## 风险

- 同一深色材质叠放对比不足会削弱活动项；活动项仅提高共享深色层级与边框，而不使用新的亮色背景。

- 侧栏底板覆盖共享卡片几何：桌面使用 `100dvh`、`border-radius: 0`，上/下/左边框为 `0`，仅保留右侧分隔线；`900px` 以下改为自动高度，只保留下边分隔线。
