# 首页同风格全站 Image 2 提示词套装计划

## 目标

基于用户提供的当前深色首页截图，为网页版 ChatGPT / Image 2 编写可直接粘贴的全站效果图提示词。提示词锁定首页导航、卡片、玻璃材质、点阵和交互动效语言，同时让馆藏、3D、预约、商城、账户和后台保留各自的真实任务结构。

## 关联需求

- F-01 至 F-14：提示词覆盖当前全部公开、账户和后台路由，不改变功能范围。
- N-03：提示词覆盖 `1440 x 900` 桌面和 `390 x 844` 移动布局、44px 控件与无溢出要求。
- N-06：本轮产物为设计提示词文档，需检查路由覆盖、文档格式和 Git diff。

## 影响范围

- `docs/prompts/2026-08-10-home-style-sitewide-image2-prompt-suite.md`：完整可复制提示词套装。
- `docs/plans/2026-08-10-home-style-sitewide-image2-prompt-suite.md`：本次范围、步骤、风险和验证记录。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：记录本轮仅完成提示词设计，尚未生成或实施页面。

## 实施步骤

1. 读取当前项目状态、`design.md`、需求追踪表、真实路由与页面模板。
2. 拆解首页参考图中的品牌、色彩、字体、导航、玻璃、卡片、点阵与动效语言。
3. 编写风格母版、共享组件状态板、13 条真实路由对应页面、移动端和纠偏提示词。
4. 检查提示词没有新增业务、没有把后台做成海报，也没有把首页高对比度机械覆盖到任务页。
5. 更新项目状态和需求追踪记录；检查 Markdown 与 Git diff。

## 验收标准

1. 用户可在网页版 ChatGPT 上传同一首页截图后，按编号逐条复制提示词生成效果图。
2. 提示词覆盖首页、馆藏、两类详情、展厅、3D、预约、商城、账户、个人中心和两个后台页面。
3. 顶部导航、移动底栏、三层玻璃、三类卡片和统一动效均有明确复用规则。
4. 包含桌面、移动、加载/空/错/成功等状态和最终一致性审查词。
5. 明确效果图只作为视觉依据，真实实现不得改变 API、路由、权限、业务状态机和 Three.js 行为。

## 风险

- Image 2 对长中文的准确率不稳定，因此提示词要求优先确认布局和材质，真实文字继续由 Vue DOM 实现。
- 静态图片不能完整表达时间型动效，因此另设共享交互状态板，并在母版中写明时长、位移、缩放和减少动态规则。
- 若一次生成多个完整页面，模型容易混合布局；套装要求一次只生成一页，并在同一对话保持参考图上下文。

- 已按 `design.md` 核对编辑式结构、河洛纸墨、三层玻璃、44px 控件、状态、动效和响应式合同。
- 已检查提示词覆盖共享导航、卡片、按钮、搜索、表单、Bottom Sheet、3D 工具、后台记录和关键状态。
- 本轮未调用网页版 ChatGPT / Image 2，未生成效果图，未修改前端代码，视觉结果需由用户后续生成并确认。
