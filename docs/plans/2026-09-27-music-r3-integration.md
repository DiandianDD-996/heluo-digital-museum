# 已认可 R3 配乐的页面接入与本地交付

> 日期：2026-09-27。状态：本地页面接入与Docker交付完成；作品已获用户认可，长时间聆听与实体设备另行验收。关联需求：F-01/F-02/F-05、N-03/N-06。

## 目标与用户确认

用户试听 R3 后确认“可以的就这版先”。将首页《入馆·河洛晨光》、水鸟阅读《水岸·静读》、青铜鼎近观《观器·温金》作为当前采用版本，保留三首的旋律、配器和场景音量关系。按既有优化方案继续完成网页素材、声音控制、代表页面回归及本地 Docker 更新；不再开展新的风格选择或重写作品。

本次确认表示作品方向获认可；不将它等同于无缝循环、实体设备、长时间阅读或生产导航已经通过。

## 影响范围与职责

- 网页素材制作：在 `scripts/music-audition/` 新增导出脚本和制作记录，在 `frontend/public/media/audio/music-r3/` 保存网页资源、来源许可及散列清单。复用后端既有公开媒体路径与Range支持，避免新增鉴权例外。已有 R1/R2/R3 无损试听文件与谱稿保留。
- 音频接入：音乐播放器、`musicDirector.ts`、`audioScenes.ts`、应用音频路由连接及对应测试；复用已有音频总线、默认静音、手势解锁和音量偏好。
- 声音控件：只修复悬停后点击关闭、Escape 焦点归还和窄屏面板位置，保留现有外观和标签。
- 文档：同步创作方案、R3确认记录、项目状态、需求追踪、长期音频架构 ADR 和本地部署说明。
- 部署：使用当前运行的根 Compose `heluo-museum` / `heluo-museum-local` 更新本机8088；保留数据库、挂载、其他项目和既有无关工作区改动。不进行公网发布、Git提交或推送。

音乐核心、资源制作、控件各有独立编辑者；主代理负责集成、文档和部署。

## 实施步骤

1. 固定认可版本并核对当前播放、偏好、路由和部署状态。
2. 输出通用浏览器可播放的压缩音乐，目标三曲合计小于6MB；只处理首尾循环衔接，不更改正文乐句。记录实际响度、峰值、循环处理和许可。
3. 替换生产背景音乐引擎，按需加载当前音乐，同曲跨页连续播放。文物阅读使用阅读稿，青铜鼎3D使用温金稿，预约和账户进一步降低存在感；后台与异常页静音。R3已包含完整空间层，不再叠原hall/bronze等持续合成环境层。
4. 补齐加载过期、快速往返、静音、隐藏恢复及失败降级；修复控制面板可操作性。
5. 运行相关单测、全量前端单测、类型检查、生产构建和资源预算；在真实后端上走代表页面与声音控制。
6. 重建并启动本机镜像，核对健康、入口与音频资源散列，复核实际页面。更新文档并审查本轮差异。

## 验收标准

- 默认静音和未解锁时不下载背景音乐；用户启用后才请求当前曲目，音乐失败不影响业务或启动旧随机音乐。
- 只有当前曲目和必要的短交接同时存在；同曲切页不重启，快速 A→B→A 和加载中关闭不恢复过期声音。
- 音乐沿现有总线接受总开关、音量档位和音乐开关控制；音效开关独立，后台与未知异常场景无音乐。
- 循环边界不含原试听导出的冗长静默，技术检查无削波/突跳；主观接缝与长时间耐听另记录。
- 首页→馆藏→水鸟→预约→青铜鼎3D可真实导航，实际曲目正确，桌面与390px声音控件可达、面板不被裁切。
- 类型、相关与全量前端单测、生产构建和既有首屏预算通过，不为了通过而提高预算。
- 本机Docker服务健康、实际资源与本次产物一致；不以Compose配置成功代替服务验收。

## 风险与验证记录

主要风险为媒体元素解锁限制、压缩编码/循环衔接、异步加载与路由竞态、声部混响在页面背景音量下的变化。使用真实浏览器与受控竞态测试验证；手机扬声器和长阅读听感保留人工验证边界。

实施前：当前本机运行 `heluo-museum:local`，镜像 `9f49ae513ccc`；R3仍为独立试听稿。已有应用和文档存在其他未提交改动，将逐文件保持。

### 实施结果

- 保留三首R3主题、编曲与场景音量，网页版本只裁去结尾约6秒极轻余响/静默，并将最后1.8秒折入开头形成原生循环。三曲分别98.2/102.3/107.6秒，共4,933,850B；与认可母带最大响度差0.024LU，削波为零。首播前1.8秒含上一轮尾音，播放器以1.4秒淡入承接；制作细节及限制见 `scripts/music-audition/EXPORT-WEB-R3.md`。
- `RecordedMusicPlayer`流式播放，沿原musicBus→duck→master输出，同曲切页不重启，跨曲1.8秒交接。快速A→B→A可复用仍在退出的旧曲，最多两个媒体。录音失败/15秒超时保持安静，隐藏页面暂停并保留位置，重新可见后等新的手势恢复。
- 当前路由停用旧持续合成环境层，生产不再导入旧随机音乐引擎。音乐和音效分别控制，默认总静音及音量档位保留。修复持久化音效关闭时首次建图仍有增益、关闭后旧异步音效复活的问题。
- 控件修复悬停后首击立即关闭、Escape未返回真实按钮、手机面板被裁切；保留主题、语言和视觉样式。
