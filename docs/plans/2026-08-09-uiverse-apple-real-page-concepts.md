# Uiverse Galaxy × Apple 青玉毛玻璃真实页面概念计划

## 目标

从本地固定版本的 Uiverse Galaxy 中筛选适合河洛数字博物馆的按钮、卡片和分段控件，并在当前 Docker 真实页面上以浏览器临时样式生成效果截图，供用户确认后再进入 Vue 实现。

## 关联需求

F-01～F-13、N-03、N-06。本轮不改变需求完成状态。

## 范围

- 读取 `design.md`、现有页面结构和真实运行数据。
- 为首页、馆藏、商城和数字展项生成桌面真实页面效果图，补充关键移动端效果图。
- 记录 Galaxy 原型路径、作者、保留特征和河洛化改造。
- 仅写入本计划和忽略目录 `artifacts/uiverse-apple-real-page-concepts/`。

## 明确不做

- 不修改任何 Vue、TypeScript、生产 CSS、API、路由、权限、数据库或 Docker 镜像。
- 不把浏览器临时注入样式描述为已经实现。
- 不在用户确认前开始组件替换。

## 入选方向

- 按钮：BurgiSimon 玻璃按压填充。
- 卡片材质：joe-watson-sbf 分层玻璃。
- 卡片触感：SteveBloX 悬停抬升与按压回落，显著收敛幅度。
- 分段控件：Admin12121 原生 radio/选中层结构。

## 验收标准

1. 截图来自当前 `http://localhost:8088` 的真实 DOM、真实媒体和真实 API 数据。
2. 截图可明确看到按钮、卡片与分段控件的目标材质，而非独立组件拼贴图。
3. 桌面至少覆盖首页、馆藏、商城、数字展项；移动端至少覆盖商城和数字展项。
4. 记录候选来源和改造差异。
5. 生产 Vue/CSS diff 保持不因本轮概念预览增加实现改动。

## 风险

- 浏览器临时样式不能证明最终组件状态机和动画实现完成。
- 当前登录态、主题和 API 数据会影响截图；最终实现仍需双主题、双尺寸和无障碍回归。

## 验证结果

- 已从当前运行前端的生产构建复制静态资源，在隔离的 `museum-ui-concept` 预览容器中仅追加概念 CSS；原 `http://localhost:8088` 与 Vue 源码未改动。
- 已生成首页、馆藏、商城、数字展项 4 张桌面实页图，以及商城、展项和展项信息 Sheet 3 张移动实页图；素材均来自真实 Vue DOM、真实媒体和当前 API 数据。
- 已生成桌面与移动端汇总板：`08-desktop-real-page-board.png`、`09-mobile-real-page-board.png`。
- 桌面 `1440×900` 与移动 `390×844` 下，四个目标路由均无横向溢出；浏览器控制台未发现问题。
- 预览地址为 `http://localhost:8091`，仅供本轮确认。尚未执行 Vue 组件替换、生产构建或 Docker 正式镜像重建。
