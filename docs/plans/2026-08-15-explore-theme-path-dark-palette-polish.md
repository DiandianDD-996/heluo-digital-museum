# Explore 主题脉络深色配色优化计划

## 目标

优化 `/explore`“河洛主题脉络”看板的深色模式，使左侧文字区、右侧河线区、边框、青玉与古铜装饰形成协调的墨玉夜色层级；保留既有构图、圆心坐标、语义 DOM、响应式和业务行为。

## 关联需求

- `F-01` 公开内容浏览
- `F-02` 内容检索与分类
- `N-03` 响应式与可用性
- `N-06` 可维护性与文档

## 参考与差异

- 用户截图：`docs/design/audit/2026-08-15-explore-theme-path-dark-palette-polish/reference-user.png`。
- 当前卡片底色接近纯黑，左上白色径向光晕过亮，左右区域反差突兀。
- 双层内框偏银白，抢过河线与标题；青玉标签偏黄，古铜与青玉主次不清。
- 山峦和竹影呈中性灰，未与墨玉底和青玉河线形成统一环境色。

## 影响范围

- `frontend/src/assets/control-surface-polish.css`
- `frontend/src/assets/ControlSurfacePolish.spec.ts`
- 本计划、验收截图、`PROJECT_STATUS.md` 与需求追踪表

不修改 Vue 结构、生产图片、API、路由、鉴权、搜索/筛选/分页、详情跳转或任何业务状态机。

## 实施步骤

1. 用墨玉黑与暖石墨建立低反差左右分区，移除突兀白色光晕。
2. 将外框、内沿与分隔线统一为低亮度古铜，压低银白边缘。
3. 分别设置暖象牙文字、青瓷绿节点和古铜中心节点，增强主次。
4. 独立调校河线、罗盘、山峦、竹影和装饰纹样的亮度、饱和度与透明度。
5. 补充深色配色契约测试，运行全量测试、类型检查、构建、Docker 与实页回归。

## 验收标准

- 左右分区可辨但不割裂，卡片不再出现大面积灰白光斑或纯黑死区。
- 标题、正文和品牌达到清晰层级；青玉标签明显区别于古铜中心节点。
- 边框克制，不比标题和河线更亮；山水竹影仅承担环境衬托。
- 原有中心圆偏差继续低于 `0.02px`，五个标签无重叠，页面无横向溢出。
- 浅色模式、移动布局和业务行为不受影响；工程门禁和正式页面通过。

## 风险

- 深色滤镜过强可能损失透明素材细节，需以正式 Docker 截图和计算样式复核。
- 颜色需避免只靠明度区分，青玉与古铜同时保持不同色相和足够对比度。
