# Explore 信息架构与视觉层级重构方案

> 状态：已实施并完成浏览器批注回修。用户已确认取消桌面一屏约束、以馆藏进入为第一任务，并按生产级整页范围推进；发布前仍需实体设备与系统辅助功能补验。

## 1. 背景与问题判断

当前 `/explore` 为了严格贴合既有 `1672×941` 效果图，将叙事标题、搜索、文化地图、分类、五件馆藏和三篇文章压入一个桌面视口。真实页面测量显示：

- 桌面正文约 `11.52px`；馆藏辅助信息与操作约 `8.96px`；文章摘要约 `8.32px`。
- 文化地图占据首屏约一半宽度，却不是主要操作，也未承担可访问的导航职责。
- 分类编号、地图编号、馆藏编号和文章编号同时出现，形成重复但无业务意义的序列噪声。
- 五件馆藏使用三种不同的信息栏方向与固定高度，访客需要反复重新学习卡片结构。
- 延伸阅读被压成 `338×154px` 横排卡，标题、摘要和操作均过小。
- 页面通过固定像素高度和隐藏页脚实现“一屏展示”，牺牲了正常滚动、字体可读性和内容呼吸感。
- `main.css`、`explore-reference.css`、深色主题和月白主题中存在多层 Explore 覆盖，后续小修容易继续增加级联冲突。

因此本轮不是继续修补颜色或单张卡片，而是取消“一屏塞完”的错误约束，重新建立任务优先的信息架构。

## 2. 已确认决策

1. 取消桌面端全部内容必须进入一屏的约束，允许正常纵向滚动。
2. 页面拆为“发现 → 筛选 → 浏览 → 延伸阅读”四段。
3. 第一任务是让访客快速找到并进入一件感兴趣的文物。
4. 文化地图降级为辅助叙事，不再占据半个首屏。
5. 按生产级整页范围规划，覆盖：
   - 浅色与深色主题；
   - 中文与英文；
   - 桌面、平板和移动端；
   - 默认、加载、搜索、无结果、错误、空分类和分页状态；
   - 键盘、减少动态、高对比度和强制颜色模式。
6. 保留 API、路由、鉴权、搜索、筛选、分页、内容详情和全部业务状态机。

## 3. 目标与非目标

### 3.1 目标

- 访客进入页面后，能够在数秒内看懂“可以搜索，也可以按主题浏览”。
- 搜索和馆藏内容成为首要层级，文化地图与文章成为自然延伸，而不是竞争模块。
- 文物图片、标题、分类和进入详情的操作在两种主题、两种语言和所有基准视口中清晰可读。
- 页面可以承载 `0`、当前 `5` 件、单页最多 `12` 件馆藏，以及搜索最多 `24` 条结果，不依赖固定五宫格。
- 新样式形成单一 Explore 所有权，减少历史 CSS 互相覆盖。

### 3.2 非目标

- 不修改后端接口、数据库、鉴权或内容发布规则。
- 不新增排序、收藏、高级筛选、搜索联想等未确认功能。
- 不替换当前已登记的五件馆藏素材，不把效果图整图放入生产页面。
- 不把 Explore 改成营销落地页、瀑布流图库或通用 SaaS 卡片墙。
- 不要求所有模块进入首屏，也不再以无滚动条作为验收目标。

## 4. 用户任务与成功标准

### 4.1 主要用户

18–30 岁的年轻文化探索者。他们通常带着模糊兴趣进入页面，希望先看到一件有吸引力的器物，再决定是否继续阅读、查看 3D 展项或预约线下参观。

### 4.2 主要动作

**搜索或选择主题，并进入一件馆藏的详情。**

### 4.3 成功信号

- 首屏只保留一个视觉主张和一个明确搜索入口。
- 搜索框与分类入口无需滚动即可看到。
- 馆藏标题、分类、时期与操作文字不小于可读下限。
- 从搜索、分类或默认馆藏进入详情的路径不超过一次选择加一次点击。
- 文章和文化脉络不会阻断馆藏浏览，但在完成浏览后自然可见。

## 5. 设计方向

### 5.1 视觉策略

- **色彩策略：Restrained（克制）**。继续使用现有“河洛纸墨”语义令牌，不增加独立页面色板。
- 浅色场景：年轻访客在日间月白展厅中翻阅一份可操作的馆藏目录，光线安静，内容清晰。
- 深色场景：年轻访客在夜间深墨档案厅中查看被暖光照亮的器物，文字仍保持任务型清晰度。
- 视觉锚点：博物馆馆藏目录、展柜说明牌、河流水系图。

### 5.2 页面签名

保留“河流”作为唯一记忆点，但只在**有标题、有标签的主题脉络区**使用河流 SVG；首屏不再放置没有解释的装饰线：

- 首屏只出现一段低对比河线作为标题与搜索之间的结构连接。
- 完整主题脉络移动到馆藏列表之后，作为“从器物到故事”的过渡。
- 河线不承担装饰性连续动画，不与搜索、分类争夺焦点。

### 5.3 克制原则

- 删除混合语言眉题 `COLLECTION EXPLORER`；语言切换后页面只显示当前语言。
- 删除不代表真实顺序或数量的 `01/02/03` 装饰编号。
- 取消馆藏卡的透视倾斜和大幅图片缩放；交互反馈仅使用边框、阴影和最大 `1px` 位移。
- 只在搜索控件、必要浮层和共享导航使用既定玻璃材质；正文内容面使用稳定实色表面。
- 不再把每个区段包成独立大卡片。

## 6. 新信息架构

```text
全局导航
└─ 发现区
   ├─ 页面标题与一句说明
   └─ 主搜索框
└─ 分类工具栏
   └─ 全部 / 动态分类
└─ 馆藏浏览区
   ├─ 区段标题与分页信息
   ├─ 一件重点馆藏
   ├─ 其余馆藏目录
   └─ 分页
└─ 河洛主题脉络
   └─ 低权重河线与主题说明
└─ 延伸阅读
   └─ 三篇文章的编辑式列表
└─ 全局页脚
```

全局页脚恢复显示；不再因为 Explore 要“一屏完整”而单独隐藏。

## 8. 模块规格

### 8.1 发现区

- 页面内容最大宽度建议 `1280–1320px`，使用 `clamp()` 控制左右留白。
- 桌面标题建议 `48–56px`，移动标题建议 `34–40px`；最多两行。
- 说明文字 `16px`、行高约 `1.65`，最大 `58ch`。
- 中文建议文案：
  - 标题：`从一件器物，走进河洛故事。`
  - 说明：`按主题浏览馆藏，或搜索一件器物，继续阅读它背后的河洛故事。`
- 英文标题允许更宽的字符行长，不能继续使用固定 `10em` 导致三至四行。
- `PointerDotField` 仅限发现区背景，降低视觉对比，不延伸到馆藏和阅读区。

### 8.2 搜索

- 继续复用 `MuseumSearchField.vue`，输入与提交按钮保持同一行；`320px` 仍应可用。
- 控件高度 `48–52px`，触控下限仍为 `44px`。
- 修复共享组件内硬编码中文的加载文案和清除按钮可访问名称，为中英文提供 props。
- 搜索后保留发现区和搜索框，仅替换下方内容区，避免页面结构突然完全改变。
- 结果标题示例：`“青铜”的 3 项结果`；右侧提供明确的“清除搜索”。

### 8.3 分类工具栏

- 删除装饰编号，不伪装为数量。
- 选中态使用主题主操作色、底边或近实色表面；未选中项保持安静。
- 每个按钮最小高度 `44px`。
- 桌面允许自然换行，不使用占满整屏的空白分段条。
- 移动端横向滚动，右侧保留渐隐或露出半个下一项，明确提示可继续滑动；强制颜色模式取消渐隐。

### 8.4 馆藏浏览

- 第一件馆藏作为重点项，但只使用一种清晰的“媒体 + 正文”结构。
- 其余馆藏采用稳定目录卡：桌面两列、平板两列或一列、移动单列。
- 卡片正文不使用绝对定位，不设置只为塞进一屏的固定高度。
- 正文字号下限：
  - 分类/时期：`14px`；
  - 普通卡标题：`20–22px`；
  - 重点卡标题：`28–32px`；
  - 操作：`14px`。
- 媒体使用稳定 `aspect-ratio` 和现有逐件焦点配置；保留水鸟安全裁切，不在 hover 时放大到越界。
- 整张卡可点击，同时保持明显的“查看器物”文案与完整焦点环。

### 8.5 主题脉络

- 从首屏右侧大卡移动到馆藏和文章之间。
- 桌面呈现为 `96–120px` 高的无外框横向区段；不使用阴影和大面积玻璃。
- 主题标签优先从实际分类数据派生；不能继续让硬编码地图与动态分类长期漂移。
- 移动端使用原生 `<details>` 渐进展开，默认收起。
- 若保持纯装饰，继续 `aria-hidden="true"`；若标签可点击筛选，则必须改为真实按钮并提供 `aria-pressed`，不能两者混用。

### 8.6 延伸阅读

- 恢复为独立区段，不再塞进 `174px` 高容器。
- 桌面三列、平板两列、移动单列；卡片不设置固定 `154px` 高度。
- 媒体建议 `16:10`，标题 `20–22px`，摘要 `14–15px`，正文最多三行。
- 使用细分隔线与留白形成编辑感，不为每篇文章叠加厚重阴影和玻璃底板。
- 操作文案统一为“阅读文章”，英文统一为“Read article”。

## 9. 主题与材质合同

页面不得继续维护独立 hex 色板，全部使用既有语义令牌：

| 角色 | 令牌 |
|---|---|
| 页面画布 | `--theme-surface-canvas` |
| 区段背景 | `--theme-surface-section` |
| 内容卡面 | `--theme-surface-content` |
| 搜索/筛选控件 | `--theme-surface-control` |
| 主文字 | `--theme-text-strong` |
| 正文 | `--theme-text` |
| 辅助文字 | `--theme-text-muted` |
| 边界 | `--theme-border` / `--theme-border-strong` |
| 主操作 | `--theme-primary-surface` / `--theme-primary-text` |
| 焦点 | `--theme-focus` / `--theme-focus-ring` |

- 浅色主题使用月白内容面与玉灰区段，器物媒体继续保留深色舞台。
- 深色主题使用深墨画布、暖象牙文字和低面积古铜操作，不把所有卡片染成棕色或绿色。
- 主题切换只改变语义材质，不改变布局、字号、内容顺序和媒体裁切。
- 页面正文卡不声明自定义 `backdrop-filter`；玻璃必须继续走既有 `data-glass` 合同。

## 10. 交互模型

### 10.1 搜索

1. 输入关键词并按 Enter 或点击搜索。
2. 搜索按钮进入 loading 状态，结果区域显示骨架，不清空输入。
3. 成功后标题宣布查询与结果数；键盘焦点不被强制抢走。
4. 清除搜索后恢复此前分类与馆藏页，不产生突兀跳顶。
5. 失败时保留关键词，显示“重试”和“清除搜索”。

### 10.2 分类

1. 点击分类后按钮立即呈现选中态。
2. 馆藏区进入骨架状态，避免旧数据与新分类状态并存。
3. 数据返回后更新馆藏和文章；通过礼貌级 `aria-live` 宣布结果。
4. 空分类提供“查看全部馆藏”，而不是只显示一句无数据。

### 10.3 卡片

- hover：边框加强、操作箭头平移不超过 `3px`；媒体最多轻微放大 `1.01–1.015`，水鸟首卡不放大。
- active：最多下移 `1px` 或缩放至 `.99`。
- focus-visible：完整卡片轮廓可见，不依赖颜色变化。
- reduced-motion：取消位移和缩放，只保留即时边框/颜色反馈。

### 10.4 页面动效

- 删除馆藏板统一 `y: 8` 的页面入场编排和卡片透视倾斜。
- 数据切换只做 `150–220ms` 交叉淡入；加载内容默认即使动画未触发也必须可见。
- 河线保持静态，不做循环流动或跟随指针的高频动画。

## 11. 状态设计

| 状态 | 页面表现 | 用户下一步 |
|---|---|---|
| 初始加载 | 标题与搜索可见；馆藏区显示一件重点骨架和四个目录骨架 | 等待或开始输入关键词 |
| 默认成功 | 分类、重点馆藏、目录、主题脉络和文章顺序展示 | 筛选、搜索或进入详情 |
| 搜索中 | 搜索按钮 loading；结果区域骨架；保留查询词 | 等待或取消/清除 |
| 搜索成功 | 统一结果卡，不使用五宫格；显示结果数 | 进入文物或文章详情 |
| 单条结果 | 使用宽内容卡但不铺满无限宽度 | 直接阅读详情 |
| 搜索无结果 | 显示查询词、简短建议、清除搜索和查看全部馆藏 | 修改或清除关键词 |
| 搜索错误 | 就地说明原因；保留关键词；提供重试 | 重试或清除 |
| 分类为空 | 说明该分类暂无已发布内容；提供查看全部 | 返回全部馆藏 |
| 内容加载错误 | 在馆藏区显示错误和重新加载，不抹去整个页面 | 重试 |
| 多页数据 | 页码和上一页/下一页均为 `44px` 控件，禁用态明确 | 翻页 |

## 12. 响应式合同

| 视口 | 发现区 | 馆藏 | 阅读 | 分类 |
|---|---|---|---|---|
| `≥1200px` | 标题/搜索双列 | 重点横卡 + 两列目录 | 三列 | 换行或单行 |
| `761–1199px` | 单列 | 重点横卡 + 两列/一列 | 两列 | 可换行 |
| `414–760px` | 单列 | 全部单列 | 单列 | 横向滚动 |
| `320–413px` | 单列，搜索保持一行 | 全部单列 | 单列 | 横向滚动并露出下一项 |

共同要求：

- 禁止 `100vw` 和关键横向溢出。
- 不通过固定卡片高度截断英文标题。
- 页面底部保留 `mobile-tab-bar` 高度、安全区和额外 `24px` 间距。

## 13. 可访问性、国际化与性能

### 13.1 可访问性

- 正文与辅助信息目标对比度不低于 `4.5:1`；大标题不低于 `3:1`。
- 有意义的内容文字不低于 `14px`；正文以 `16px` 为基准。
- 搜索、筛选、分页和卡片保持可见焦点与至少 `44px` 触控目标。
- 标题顺序固定为一个 `h1`，随后为“馆藏器物”“主题脉络”“延伸阅读”三个 `h2`。
- 骨架不重复播报；错误使用 `role="alert"`，结果更新使用礼貌级 live region。
- 强制颜色模式取消材质、渐隐和阴影，但保留边界、当前项和焦点。

### 13.2 国际化

- 删除共享搜索组件中的中文硬编码。
- 中英文使用同一 DOM 结构，不为英文复制另一套布局。
- 英文标题不锁定窄字符宽度；按钮标签始终单行。
- 搜索结果数量、分页和空状态使用完整的中英文文案映射。

### 13.3 性能

- 第一件重点馆藏图片可使用 eager / high priority，其余保持 lazy。
- 图片容器声明尺寸或 `aspect-ratio`，避免内容载入时布局跳动。
- 继续复用当前 WebP；只有实测表明体积影响明显时再生成响应式尺寸，不在本轮盲目扩充素材。
- 不为文化地图引入 canvas、WebGL 或新动画依赖。
- 页面切换与筛选不增加新的持续 RAF。

## 17. 主要风险与应对

| 风险 | 应对 |
|---|---|
