# 月白厅堂浅色主题实施计划

- 日期：2026-08-14

## 1. 目标

将现有浅色主题从“高亮画布叠高亮卡片”升级为“月白厅堂”三层材质系统：冷灰青 L0 画布、低彩玉灰 L1 页面分区、暖月白 L2 内容面，以及略深的石材 L3 控件面。保留河洛墨绿正文/主操作与少量古铜引导，使页面有稳定前后景关系，降低审美疲劳。

本轮同时处理用户浏览器标注：

1. 首页策展带的文物图不再像突兀贴图；
2. Explore 中间文物卡不再使用闷重的深墨绿文字区；
3. 3D Dock 的“点云模式”和导览步骤字体提升到可直接阅读的尺寸与对比；
4. 预约页按已选视觉母版形成清晰的任务画布、日期卡和票券表单层级。

## 2. 关联需求与硬边界

- 需求：`F-01/F-02/F-03/F-05/F-06/F-08/F-09/F-12/F-14/N-03/N-06`。
- 仅改前端主题令牌、页面样式与视觉契约测试。
- 不改 API、数据库、路由、鉴权、预约/订单状态机、购物车行为、Three.js 生命周期、媒体 URL 或已验收的深色主题。
- 保留现有真实文物、馆舍、展厅图片；不把生成效果图直接放入生产页面。

## 3. 实施范围

| 层级 | 动作 |
| --- | --- |
| 主题基础 | 新建后置样式层，集中定义月白厅堂的 L0-L3 令牌、边界、焦点、控件和浅色 `data-glass` 实色降级。 |
| 首页 | 将策展带分成玉灰底带、暖月白文物卡、低调媒体舞台，给图片加入一致的石材底/内框与受控色调。 |
| Explore | 保留五件器物和拼接几何，将浅色主题的文字区改为暖月白纸本，深墨仅留给图片舞台/局部遮罩。 |
| 3D | 不改 Canvas/模型；将浅色 Dock、工具和面板拉开 L1/L2/L3 层级，Dock 模式和六段导览使用可读字号。 |
| 预约 | 左侧玉灰任务场，日期/时段为暖纸控件，右侧为更暖的票券表单面；现有日期、时段、表单和移动 Bottom Sheet 行为不变。 |
| 全局补齐 | 登录、个人中心、商城、内容/运营后台通过 L0-L3 令牌统一表面关系，不重排其信息架构。 |

## 4. 验收标准

1. 浅色模式相邻 L0/L1/L2/L3 至少同时体现背景差与 1px 边界；普通内容卡不再是纯白叠纯白。
2. 首页、Explore、3D、预约在 `1708x898` 与 `390x844` 无横向溢出，真实业务入口可用。
3. Explore 中间卡文字区的浅色背景与文物舞台明显分层；主页文物缩略图拥有统一克制的媒体底。
4. 3D Dock “点云模式”和导览步骤的桌面实测字号不低于 `13px`，文字与背景可区分。
5. 深色主题计算样式不被浅色选择器覆盖；`prefers-reduced-transparency`、高对比度和强制颜色保留既有降级。
6. 类型检查、相关 Vitest、生产构建、页面映射与指针体积门禁通过；Docker 真实页面完成双尺寸浅深主题复核。

## 5. 风险与回退

- 当前工作区包含大量用户已有未提交修改；只在新后置样式文件、导入、相关测试和项目文档中加入本轮内容，不重置或覆盖无关改动。
- 历史 `main.css` 与页面级样式存在高特异性选择器；通过后置、仅浅色作用域覆盖，实际 Docker 页面以 computed styles 为准。
- 3D 的 WebGL `X4122` 为既有驱动精度 warning，本轮不改着色器；若出现新的应用级错误则单独定位。
