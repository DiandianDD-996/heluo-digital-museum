# Explore 主题脉络参考图还原计划

## 目标

按照用户提供的 `1672 x 941` 完整效果图，重建 `/explore` 的“河洛主题脉络”卡片。还原重点是横幅比例、左文右图构图、暖月白纸面、青玉河线、古铜节点、水墨山峦和竹影层次；页面文字、品牌和五个主题节点继续由真实 Vue DOM 渲染。

## 关联需求

- `F-01` 公开内容浏览
- `F-02` 内容检索与分类
- `F-03` 文物与专题详情入口
- `N-03` 响应式与可用性
- `N-06` 可维护性与文档

## 视觉合同

- 桌面卡片为宽幅月白纸面，左侧约三分之一承担品牌、章节标签、标题和说明；右侧为青玉河线及五个交错标签。
- 中部使用细古铜竖向分隔，右侧中心节点叠加罗盘纹饰；底部为低对比度山水，右侧为竹影。
- 完整效果图只用于对照，不作为线上背景；标题、品牌、说明、节点标签均为可选择、可翻译的真实文字。
- 移动端改为上下构图，保持节点可读并禁止横向溢出；不把桌面卡片整体缩小。
- 深色主题保持相同几何，使用深墨纸面、降低亮度的装饰和可读文字；减少透明度、高对比度与强制颜色模式提供实色降级。

## 实施步骤

1. 归档九张用户输入图，并从透明装饰素材生成轻量 WebP。
2. 用语义 DOM 重建品牌、标题和五个主题节点，删除旧网格 SVG。
3. 在最终后置样式层实现桌面、平板、移动、双主题及辅助功能降级。
4. 更新专项契约测试，验证文字未烘焙、素材版本化、五节点仍为真实 DOM。
5. 运行专项测试、前端全量测试、类型检查、生产构建与 `git diff --check`。
6. 重建正式 Docker 前端并在目标桌面、移动、浅色、深色和中英文页面复核几何、图片、溢出与控制台。

## 验收标准

- 卡片构图和视觉层次与完整效果图一致，不再出现旧网格路线板。
- 五个标签在中文和英文下均不重叠、不断裂到不可读，装饰图片均为空 `alt`。
- `975 x 898`、宽桌面和 `390 x 844` 无页面级横向溢出，图片成功解码。
- 浅色、深色、减少透明度、高对比度和强制颜色模式有明确样式合同。
- 搜索、筛选、分页和详情入口行为不变；相关工程门禁通过。

## 风险

- 用户素材包含大尺寸透明 PNG，需压缩后上线，避免影响页面传输。
- 完整效果图的文字和品牌不能作为位图复用，否则会破坏国际化和可访问性。
- 窄屏无法保留桌面交错距离，需以节点可读和无横向溢出优先。
