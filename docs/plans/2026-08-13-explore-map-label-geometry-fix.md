# Explore 文化地图文字与主题位置修复计划

## 目标

修复 `/explore` 文化地图中的 SVG 标签被横向压缩，以及切换浅色/深色主题时地图标题和路线标签位置不一致的问题；保持现有地图内容、页面结构、搜索、筛选、路由和业务逻辑不变。

## 关联需求

- F-01：游客浏览并按分类筛选已发布内容。
- N-03：桌面和移动端布局可用，文字清晰可读。
- N-06：浅色与深色主题保持一致的组件几何和视觉层级。

## 根因

- SVG 使用 `preserveAspectRatio="none"`，随卡片宽高非等比缩放，文字轮廓也被一并拉伸。
- 历史深色规则将地图标题改为文档流布局，而浅色仍使用绝对定位；多层响应式覆盖又给两套主题设置过不同的 SVG 高度，导致主题切换时坐标基准变化。

## 实施

1. 将地图 SVG 改为等比缩放，并收敛视图框高度与装饰支流，保证五个标签完整落在稳定坐标系中。
2. 在最终 Explore 作用域规则中，让浅色和深色共用标题定位、SVG 边界与移动端内边距。
3. 增加主题几何契约测试，禁止回退到非等比缩放或主题专属坐标。
4. 运行专项测试、类型检查、生产构建、Docker 实页双主题与桌面/移动回归。

## 验收标准

- 五个 SVG 标签字形比例正常，无横向压扁。
- 同一视口切换浅色/深色后，地图标题和五个路线标签的边界坐标保持一致。
- 桌面与 `390x844` 移动端无裁切、遮挡或横向溢出。
- 搜索、筛选、路由、API 和主题颜色不受影响。

## 风险与回退

- 等比缩放可能在极端宽高比下产生少量留白；以保持文字可读和坐标稳定为优先。
- 回退只需撤销本计划对应的 SVG、Explore 最终覆盖规则和契约断言，不涉及数据或接口。

## 验证结果

- SVG 已改为 `viewBox="0 0 720 250"` 与 `preserveAspectRatio="xMidYMid meet"`；深浅主题共用地图标题和 SVG 舞台定位，移动端标签以 SVG 内部 `20px` 字号补偿等比缩放。
- `pnpm test` 通过：31 个测试文件、141 项；`pnpm typecheck`、`pnpm build`、专项主题/玻璃契约 25 项和 `git diff --check` 均通过。生产构建只保留既有 `@vueuse/core` PURE 注释和 Three.js 大分包提示。
- 正式 Docker 前端已重建并运行，`http://localhost:8088/explore` 返回 `200`。
- 正式实页在 `1708x898` 下，浅色/深色地图卡、标题、SVG 和五个标签的坐标与尺寸逐项一致，标签高度约 `16px`；在 `390x844` 下五个标签坐标逐项一致，标签高度约 `12.67px`。两档均无横向溢出，截图目视无裁切或遮挡。
- 未改 API、路由、搜索、筛选、分页、鉴权或业务状态机；实体手机、触控笔和 Windows 系统级强制颜色未重复验收。
- 后续完整效果图还原已在 `docs/plans/2026-08-11-explore-asset-led-visual-optimization.md` 的“四次完整效果图最终还原”中完成：最终全量为 32 个测试文件/144 项，正式目标视口更新为 `1672×941` 与 `390×844`，地图双主题几何仍保持一致。
