# 公开页面导航栏配色统一

## 目标

统一深色主题下首页与其他公开页面的顶部导航栏配色，以当前首页的近黑、暖象牙与低面积古铜金导航为共享基准，不改变页面主体、路由、鉴权或交互行为。

## 关联需求

- F-01、F-05、F-12
- F-14、N-03、N-06

## 影响范围

- `frontend/src/assets/main.css`
- `frontend/src/assets/darkThemeCohesion.spec.ts`
- `design.md`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

## 实施步骤

1. 将首页专用的深色导航选择器改为公开页面共享选择器。
2. 保留首页电影感主体和各内页画布、卡片、表单配色，不修改浅色主题。
3. 更新主题契约测试，要求导航共享并禁止重新引入首页专用配色分支。
4. 运行专项测试、前端全量测试、类型检查、构建、页面门禁和实际页面验证。

## 验收标准

- 深色首页和公开内页的导航背景、边框、馆印、文字、当前项及工具按钮使用同一套配色。
- 首页主体仍保留夜间馆廊的独立视觉层。
- 浅色主题、公开路由、管理员入口、主题切换和语言切换行为不变。
- 相关自动化检查通过，桌面和移动端无新增溢出或控制台错误。

## 风险

- 历史 CSS 存在多层导航覆盖，需使用与玻璃契约相匹配的选择器优先级。
- 数字展项曾有独立导航配色，统一后需纳入公开路由回归。
