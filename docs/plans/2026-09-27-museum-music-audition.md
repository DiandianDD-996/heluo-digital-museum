# 河洛配乐第一轮可播放小样

> 日期：2026-09-27。状态：首轮三场景试听稿与独立试听页已生成，等待用户听感反馈。
> 关联：F-01/F-02/F-05、N-03/N-06；审美依据为 `2026-09-27-museum-music-art-direction.md` v0.3，沿用 v0.2 已确认的创作原则。

## 目标

交付三份约 56 秒可独立播放的原创编排试听稿：首页迎宾、水鸟阅读、青铜鼎近观。按各场景组织乐句，清润、自然、雅俗共赏；阅读时保留旋律氛围但不抢注意力。用户听过后再细化，不把小样等同最终背景乐。

## 范围与制作方式

- 新建 `scripts/music-audition/score.json`、`SCORE.md` 保存原创事件谱与创作说明。
- 新建 `scripts/music-audition/render.py`，使用本机已有 Python / NumPy / SciPy 进行样本移调、自然包络、空间、离线混音及验证，不增加前端依赖。
- 新建 `scripts/music-audition/listening.html`、`check-preview.mjs` 与 `README.md`，提供独立试听页面、可重复的播放器验证与操作说明。页面采用克制的青瓷色与清楚分区，使用单个原生播放器避免叠音；不加载第三方字体或网页脚本。
- 二进制音源、试听 WAV、指标和预览产物存放于已忽略的 `artifacts/music-audition-2026-09-27/`。
- 音源选择公开 VSCO-2-CE 中适量录音，固定提交与 CC0 许可，保存来源、原始音高、散列和许可文本。竖琴/长笛明确标注实际音源，不冒充古琴/箫的真人演奏。
- 本轮只制作试听稿，不修改产品音频模块、数据库或运行中的 Docker。最终音源品质、网页音量、无缝循环及完整曲长仍需后续验收。

## 步骤与独立分工

1. 音源核验与有限样本获取，由音源子任务负责 `source-samples/`，记录许可与原始技术信息。
2. 原创作曲数据由编曲子任务负责 `score.json` / `SCORE.md`。主代理负责离线渲染、结果检查与交付。
3. 校准音源起落、声部相对音量和空间，不使用旧随机游走音序。
4. 导出三份同响度对比稿及建议场景音量版本，保存可复现的谱稿、渲染参数和校验指标。
5. 检查文件可解码、时长、双声道、非静音、起落连续性、削波/峰值和三曲响度差；提供可播放文件，再收集用户具体片段反馈。

## 风险和验收边界

采样编排并非现场乐团录音；音源移调、延长或拼接可能有不自然之处，需试听反馈修订。自动频谱、峰值与响度检查不能证明悦耳或不影响阅读，也不能代表真机扬声器验收。首批作品是独立短段，尚未做长时间循环与产品导航验收。
