# 撤回文物数据透镜鼠标动效

## 目标

根据用户实页反馈，立即撤回“文物数据透镜”的椭圆轨道设计，恢复上一版本已经确认相对更好看的数字文物扫描场；不继续叠加新的主观造型。

## 关联需求

- F-01 / F-02 / F-03 / F-05 / F-09：公开前台视觉与鼠标交互。
- N-03 / N-06：媒体偏好、输入降级、性能与资源释放。

## 影响范围

- `PointerDotField` 绘制与几何参数。
- 对应组件和纯函数测试。
- 项目状态、需求追踪与本计划。

不修改业务、路由、API、Three.js、后台或后端。

## 实施步骤

1. 删除椭圆轨道、古铜短弧、轨道采样节点和方向角缓动。
2. 精确恢复上一版本的点阵密度、位移、环形能量波、相邻拓扑与小型扫描刻度。
3. 恢复 `data-effect="artifact-scan"` 及对应测试断言。
4. 运行前端测试、类型检查、构建、体积、性能和页面映射。
5. `--no-cache` 重建 Docker 前端并在生产实页确认椭圆圈已消失。
6. 更新状态与需求追踪，审查 diff，不自动提交。

## 验收标准

- 页面不再出现当前版本的椭圆轨道圈。
- 实际效果恢复到上一版本的数字扫描点阵表现。
- 既有减少透明度、减少动态、pen/touch、低帧降级和静止停帧规则不变。
- 自动化、Docker 和浏览器实页验证通过。

## 风险

- 恢复上一版本也会恢复其相对更明显的局部网格；本轮以用户明确选择的版本为准，不再擅自改造。
