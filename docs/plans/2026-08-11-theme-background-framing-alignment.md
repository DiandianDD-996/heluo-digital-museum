# 首页与购物页双主题背景构图统一

## 目标

统一首页和购物页在浅色、深色主题切换时的背景区域尺寸与主体视觉比例，不拉伸图片，不改变页面内容、商品、路由、主题状态或交互行为。

## 关联需求

- F-01、F-09、F-12、F-14
- N-03、N-06

## 影响范围

- `frontend/src/assets/main.css`
- `frontend/src/assets/darkThemeCohesion.spec.ts`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

## 当前差异

- 首页桌面主视觉浅色高度为 `680px`，深色为 `720px`；移动端浅色为 `760px`，深色存在约 `654px`、`500px` 和 `620px` 的独立覆盖。
- 首页浅色背景为 `1586x992`，深色背景为 `1672x941`；购物页浅色背景为 `1536x1024`，深色背景为 `1672x941`。不同宽高比在同一 `cover` 规则下会产生不同的主体视觉比例。

## 实施步骤

1. 删除首页深色主题专用高度覆盖，让双主题共享桌面和移动端主视觉高度。
2. 仅在桌面背景舞台校正深色首页和深色购物页的背景缩放，使中央器物与浅色版本接近同一视觉比例。
3. 移动端继续使用 `cover`，避免窄屏露底；保留各主题独立背景素材和遮罩。
4. 更新主题契约测试，运行前端测试、类型检查、构建、页面门禁、Docker 和正式页面双主题回归。

## 验收标准

- 同一视口下，首页浅色与深色主视觉容器宽高完全一致。
- 购物页浅色与深色背景舞台宽高完全一致，主器物视觉比例不再明显跳变。
- 两页主题切换后无图片拉伸、露底、横向溢出或内容遮挡。
- `1440x900` 与 `390x844` 双主题页面无控制台错误。

## 风险

- 两组素材不是同一张图片调色版，无法做到逐像素构图一致；本轮只统一容器与主体视觉比例。
- 桌面缩放校正必须限制在背景舞台，不得影响移动端和商品卡图片。
