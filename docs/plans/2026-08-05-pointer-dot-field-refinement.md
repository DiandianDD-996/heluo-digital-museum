# 鼠标小光点与河图点阵波场优化

## 目标

移除桌面自定义光标的大尺寸几何外环，保留 `6px` 青玉发光点；参考 Chanly 的鼠标驱动点阵逻辑，在首页、馆藏、数字展厅列表和商城顶部主视觉加入河洛青玉与少量古铜金组成的局部波场。

## 关联需求

- F-01 / F-02 / F-03 / F-05 / F-09：公开前台浏览、馆藏、数字展厅与商城交互。
- N-03：响应式、触控和辅助功能降级。
- N-06：前端性能、资源释放与浏览器兼容。

## 影响范围

- 全局桌面精细指针组件与指针视觉样式。
- 新增复用 Canvas 点阵组件及纯计算工具。
- 首页、馆藏、数字展厅列表、商城顶部主视觉挂载。
- 指针单元测试、性能体积审计和页面映射审计。
- 项目状态与需求追踪记录。

不修改后端、业务 API、路由、数据结构、Three.js 展项交互、表单、后台或购物袋逻辑；不新增第三方依赖。

## 实施步骤

1. 删除自定义光标外环 DOM、跟随状态和圆环样式，保留固定 `6px` 小光点及意图/按压反馈。
2. 新增 `PointerDotField`，使用共享 RAF、非响应式坐标、可见性与尺寸观察器完成局部点阵位移和回弹。
3. 按既定四个顶部主视觉挂载，每页最多一个 Canvas，并明确内容层级与点击穿透。
4. 接入 full/restrained/static 档位、键盘、触摸、触控笔、媒体偏好、页面隐藏、离屏、低帧率和卸载降级。
5. 更新单元测试、页面映射、性能和体积门禁，执行完整前端验证与浏览器截图检查。
6. 验证通过后更新 `PROJECT_STATUS.md` 和需求追踪表。

## 验收标准

- 自定义光标只有 `6px` 小光点，不存在几何外环；链接/操作只增强光晕，危险态变色，按压缩放至 `72%`。
- 四个目标主视觉各有且只有一个点阵 Canvas；其他页面、3D Canvas、后台与内容区没有点阵。
- 点阵采用 `18px` 间距、青玉/古铜金 `90%/10%` 稳定分布、最大 `22px` 位移、最大 `1.6` 倍点缩放和 `1.5` DPR 上限。
- 鼠标静止后停止 RAF 并保留局部形变；离开后回到基线并停止 RAF。
- restrained/static、触摸、触控笔、粗指针、减少动态、减少透明度、高对比度、强制颜色和键盘模式不运行动画。
- 页面隐藏、离屏和卸载后共享 RAF 订阅数为零；无横向溢出、控件遮挡、点击回归或控制台错误。
- 单元测试、类型检查、生产构建、页面映射、指针性能、交互体积和 `git diff --check` 通过。

## 风险

- Canvas 与主视觉现有伪元素、玻璃材质可能产生层级冲突；通过独立 stacking context 和明确内容层解决。
- 高密度点阵可能提高低性能设备负担；仅 full 档启用，DPR 封顶，并在静止、离屏、后台和低帧率时停帧。
- 浏览器测试环境可能没有真实粗指针或实体触控笔；自动化覆盖媒体与合成输入，实体手感若无法复测必须保留为未验证项。

## 验证结果

- 实现完成：删除 `28px / 38px / 42px` 外环，只保留固定 `6px` 青玉光点；首页、馆藏、数字展厅列表和商城顶部各挂载一个 `PointerDotField`，未改后端、业务 API、路由、数据结构或 Three.js 交互。
- 点阵契约完成：`18px` 间距、稳定 `90% / 10%` 青玉与古铜分布、`170px–280px` 影响半径、`22px` 最大位移、`1.6` 最大缩放和 `1.5` DPR 上限均由纯函数测试覆盖。
- 生命周期完成：使用共享 RAF 与非响应式坐标；静止、离开、隐藏、离屏、档位降级及卸载均停止订阅。首次临界低帧后保留一个有上限的 20 帧复核窗口，使连续两次低于 `40fps` 的静态降级策略可实际触发。
- 输入与辅助功能完成：根元素档位事件可立即关闭 Canvas；touch、pen、coarse pointer、减少动态、减少透明度、高对比度、强制颜色、键盘模式和低性能档均使用系统指针或禁用波场。
- 回归修复：首页点阵层级规则曾覆盖 `.corridor-home__routes` 的绝对定位，导致路线卡被裁到视口外；已改为只设置 `z-index`，并新增 CSS 防回归测试。生产实页计算为 `position: absolute`、`transform: none`，导航卡完整位于视口内。
- `pnpm test`：20 个测试文件、70 项全部通过。
- `pnpm typecheck`：通过。
- `pnpm build`：通过；仅保留既有 Three.js 大分包和第三方纯函数注释警告。
- `pnpm qa:pointer-pages`：首页、馆藏、数字展厅列表和商城在八档尺寸共 32 组通过；无横向溢出、控件裁切，目标主视觉各一个非阻塞且有像素的 Canvas，full 档可激活。
- `pnpm perf:pointer`：16 项门禁全部通过；包括普通页/3D CPU 1x/4x、点云运行、后台 5 秒零帧、连续低帧静态降级、媒体偏好、200% 等效视口、混合触控笔和触摸模式。
- `pnpm perf:pointer-size`：通过；交互 JS 为 `14,571 B minified / 5,398 B gzip`，低于 `18,000 B / 7,000 B` 预算。
- 浏览器与服务：四个目标页桌面截图已目视检查；首页回归修复后再次在实际 Chrome 视口检查。`http://localhost:8088/` 返回 `200`，`/api/v1/health` 返回 `UP`。
- Docker：标准构建因 Docker Hub 请求超时未完成；使用同一次通过检查的 `dist` 更新 Nginx 并固化本地 `deploy-frontend:latest`，随后通过 `--no-build` 从该镜像重建前端容器。运行容器与本地标签均指向 `sha256:f5dfe6afc93485c6f2352a27346435eaa3e919fac8670c1c9c0e5f66759d9697`。
- `git diff --check`：通过，仅输出仓库现有 LF/CRLF 转换警告。
- 未验证：本轮未重新执行真实手机、触控笔和高刷鼠标的实体手感复测；自动化媒体、合成 pen/touch 与性能降级证据已通过。

### 首页标题回归修复

- 用户截图暴露首页中文标题上下笔画遮挡；根因是中文标题 `.92` 行高与逐行裁切容器的负 `margin-block` 同时压缩可见区域。
- 保留 GSAP 逐行揭示和 `overflow: hidden`，将中文标题行高调整为 `1.04`，删除负外边距并增加 `.08em` 上下安全内边距；英文 `.is-english` 规则保持不变。
- 移动端主视觉最小高度由 `680px` 调整为 `760px`，避免标题增高后简介进入底部路线卡；新增 CSS 契约测试，禁止中文标题行高低于 `1`、负 `margin-block` 回归，并锁定移动端安全高度。
- 最终验证：20 个测试文件 72 项、类型检查、生产构建通过；`1433x746`、`900x890` 四行标题和 `390x844` 生产页面无笔画裁切或横向溢出，手机简介与路线卡约 `34px` 净空，控制台无警告/错误。
- 同一生产构建产物已固化为 `deploy-frontend:latest` 并通过 `--no-build` 重建前端容器；运行容器和本地标签均为 `sha256:c85d915ac546b6c7a22d490353529d2cf47d4efe4f666a12832e6a179d6561c5`。
