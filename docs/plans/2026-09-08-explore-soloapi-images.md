# 探索器物图片生成

## 目标与范围

按用户指定的 soloapi-image2 技能及 `docs/design/2026-09-08-explore-image-prompts.md`，以五张现有原图为造型参考，生成统一背景与柔光的概念器物摄影图。关联 F-01/F-02/N-03。当前用户指定 API 生成，优先于旧提示词文档中的网页版操作说明。

## 步骤与验收

1. 验证技能配置，查看五张原图；提取统一提示词和逐件补充要求。
2. 先生成水鸟检查风格，再生成青铜爵、玉璧、陶罐与石板。
3. 检查输出文件、尺寸、主体完整性、背景装饰去除与风格一致性；保存输入和输出对应记录。
4. 更新素材记录、项目状态和需求追踪。只生成新文件，不覆盖生产资源、不部署、不提交 Git。

风险：生成模型可能改变细小纹样，结果为概念展品素材，不作为真实文物档案。当前尚未进行网页裁切与替换验收。
