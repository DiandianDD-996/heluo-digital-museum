# 鼠标双圆与点阵配色精修

## 目标

根据用户对当前实页的直接反馈，保留“小圆拖拽大圆”的交互机制，仅精修色彩：将大圆边框从偏青绿荧光收束为月白—香槟金属边；将点阵中偏土黄的辅助节点替换为更明亮、偏黄金黄的数字鎏金色。

## 关联需求

- F-01 / F-02 / F-03 / F-05 / F-09：公开前台品牌展示与鼠标交互。
- N-03 / N-06：视觉可读性、输入降级、性能与可维护性。

## 设计决策

1. 光晕边框采用“月白高光 + 香槟金属边 + 很浅的青玉内光”：轮廓清晰但不再是高饱和青绿霓虹。
2. 点阵保留青玉为主色；原 `bronze` 辅助节点统一转向“数字鎏金”黄，提升明度并减弱土褐/橙感。
3. 同步调整普通图片背景、浅色背景和减少透明度三套 Canvas 调色，防止辅助节点在任一模式回到土黄色。
4. 不改交互曲线、尺寸、路由、业务、Three.js 或无障碍降级。

## 验收标准

- 大圆边框在浅色展厅照片上清晰、精致，视觉重心是月白/香槟金属感而非青绿光圈。
- 点阵辅助节点表现为偏金黄的高亮，不出现暗土黄或橙褐色。
- 类型、测试、构建、性能/尺寸门禁、Docker 和生产实页回归通过。

## 风险

- 金色过亮会抢占首屏文字和鼎的注意力，须保持辅助节点面积稀疏、仅在指针附近提升亮度。
- Canvas 像素调色不受 CSS 令牌自动约束，三种 palette 必须一起验证。

## 验证结果

- Canvas palette 已由 `baseBronze/activeBronze` 语义替换为 `baseGold/activeGold`：图片主视觉为 `rgba(216,178,79,.36)` / `rgba(245,202,70,.88)`，浅色主视觉为 `rgba(199,158,42,.30)` / `rgba(231,184,40,.84)`；减少透明度使用同方向的不透明金黄。
- `corepack pnpm test`：23 个测试文件、79 项通过；定向色彩/光晕测试 3 个文件、15 项通过。`corepack pnpm typecheck`、`corepack pnpm build` 和 `corepack pnpm perf:pointer-size` 通过，交互体积 `16,290 B`（gzip `6,080 B`）。
- `HELUO_PERF_DURATION_MS=2000 corepack pnpm perf:pointer` 的 16 项门禁通过；`corepack pnpm qa:pointer-pages` 的首页、馆藏、展厅、商城 32 个尺寸组合通过。
- Docker 前端使用 `--no-cache` 重建并强制替换，运行镜像为 `sha256:7491f9cbd574bdf28932d655fc4e1444bdd048116a7b58567899e3c6f2536149`；首页 HTTP `200`，容器内 `/actuator/health` 返回 `UP`。
- 生产首页 `1440×900` 实页确认大圆为香槟月白边且处于拉拽态，点阵辅助节点为金黄色，无横向溢出，控制台错误为空；截图在 `artifacts/page-mapping/home-dual-circle-metallic-gold-1440x900.png`。
