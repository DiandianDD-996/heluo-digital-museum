# Explore 素材驱动视觉优化计划

## 目标

依据用户提供的 Explore 素材与完整桌面效果图，优化 `/explore` 的深色 Explore 馆藏探索体验：使用真实文物媒体和生成的河流纹理背景，按 `1672×941` 参考图还原标题、搜索、分类、文物卡片和延伸阅读的视觉层级；保留 API、搜索、分类筛选、分页、路由、鉴权和移动底部导航。

## 关联需求

- F-01：游客分页浏览已发布的文物和文章，并按分类筛选。
- F-02：游客通过关键词搜索文物和文章。
- F-03：游客进入文物和文章详情。
- N-03：桌面和移动端可用，核心控件可达。
- N-06：视觉系统、状态、主题和响应式行为一致。

## 素材审查结论

| 输入 | 结论 | 用途 |
|---|---|---|
| Jade Bi、Painted Pottery Jar、Bronze Jue、Water Bird Bronze、River Map Stone 五张 `1254×1254` 图片 | 合格 | Explore 文物卡片和文章卡片媒体 |
| 深墨河流背景 `1672×941` | 合格 | 深色 Explore 页面环境背景 |
| 桌面效果图 `1672×941` | 合格 | 桌面布局和视觉层级参考，不作为生产整图 |
| 完整桌面效果图 `1672×941` | 合格 | 本轮桌面端间距、地图高度、馆藏板和阅读栏的最终还原参考，不作为生产整图 |
| 移动效果图 `941×1672` | 合格 | 移动布局和底部导航参考，不作为生产整图 |

效果图中的文字、导航、搜索框、地图、卡片边框和按钮均不进入生产图片；这些内容继续由 Vue、CSS 和 SVG 渲染。原有五张器物图和无文字背景图审查合格；为匹配完整桌面参考的深墨环境与右侧浅玉璧高卡，额外使用内置 `imagegen` 生成两张无文字生产媒体：`explore-reference-ink-river-imagegen-v1.webp` 与 `explore-jade-bi-light-imagegen-v1.webp`。

## 影响范围

- `frontend/src/views/ExploreView.vue`：使用用户提供的版本化文物图，文章卡片复用同一媒体映射，删除不符合标题的旧视觉替换。
- `frontend/src/assets/main.css`：仅增加 Explore 作用域的深色背景、英雄区、地图、搜索、筛选、文物卡片和延伸阅读样式，以及移动响应式覆盖。
- `frontend/public/media/editorial/`：保存用户提供素材和本轮生成素材的版本化 WebP，不覆盖既有资产。
- `frontend/public/media/editorial/README.md`：记录素材来源和用途。
- 既有 Explore/API/共享组件测试：覆盖素材映射之外的搜索、分类、路由和共享页面行为；本轮不新增测试文件，避免重复覆盖。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：完成后记录实际验证结果。

## 实施步骤

1. 将临时 PNG 输入转为版本化 WebP，并保存两套桌面/移动效果图及本轮完整桌面效果图作为设计证据。
2. 审查既有器物图，生成并验收深墨环境底图与浅色玉璧卡片舞台，再接入五张文物媒体；不改变 API 数据结构。
3. 按完整桌面参考收敛深色 Explore 的标题、搜索框、分类筛选、文化地图、文物板和延伸阅读层级。
4. 保持浅色主题、搜索结果、加载、错误、空状态、键盘焦点和减少动态降级可用。
5. 运行现有前端测试、全量类型检查、生产构建、`git diff --check` 和真实 `/explore` 桌面/移动页面回归。

## 验收标准

- 深色 `/explore` 使用版本化深墨河流环境底图和五张新文物媒体，右侧玉璧高卡使用浅色玉璧舞台。
- 青铜爵显示爵，玉璧显示玉璧，不再使用青铜鼎或玉猪龙替代错误素材。
- `1672px` 桌面端还原完整参考比例：地图约 `290px` 高，筛选条约 `48px` 高，馆藏板为 `176px + 136px` 的不对称策展网格，左侧主卡、中部宽卡、右侧高卡和下方两张小卡，阅读区为左侧标题加右侧三卡横排。
- 移动端搜索、地图、文物卡片和文章卡片不横向溢出；底部导航不遮挡内容。
- 搜索、分类、分页和详情跳转业务行为不改变。
- 生产图片不包含网页文字或 UI；效果图只作为设计参考留档。
- 类型检查、相关测试、生产构建和页面回归结果真实记录，失败项不隐瞒。

## 风险

- 用户提供的 PNG 文件体积约 1.8–2.4MB/张，生产页面使用 WebP 压缩版本；原始临时文件不作为运行时依赖。
- 深色背景会增加页面氛围，但必须保留文本对比度和高对比度/减少透明度降级。
- 当前工作区已有大量未提交改动，本轮只编辑本计划列出的 Explore、素材和文档文件，不重置、提交或处理无关改动。
