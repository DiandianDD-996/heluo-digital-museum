# 商城桌面商品卡片位置重排计划

## 目标

修复商城桌面端三张商品卡片的空间关系：第一、第二张卡片保持明确水平间距并错开纵向位置；第三张卡片从过高的位置下移到右侧中上区域。移动端继续使用单列商品卡片，不改变购物车、分类筛选、加购和模拟支付逻辑。

## 关联需求

- F-09：游客可浏览商品并维护购物车。
- N-03：桌面和手机端布局可用且无关键横向溢出。
- N-06：保持既有河洛纸墨视觉系统和可维护 CSS 契约。

## 影响范围

- `frontend/src/assets/main.css`：仅调整 `981px` 以上商城商品卡片的最小舞台高度、三张卡片的定位和间距。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：记录本次视觉布局修复与验证结果。

## 验收标准

1. 桌面端第一、第二张商品卡片不重叠，卡片之间保留稳定间距。
2. 第三张商品卡片不再贴近商品舞台顶部，且仍位于右侧、不会遮挡商城标题和购物袋。
3. `981px` 以下平板/移动端不使用绝对定位重排；分类筛选、加购和购物车交互保持不变。
4. 前端测试、类型检查、生产构建和差异空白检查通过。

## 实施结果

- 使用末尾 CSS 覆盖收敛旧版分散定位规则：商品舞台扩大到 `clamp(380px, 42vh, 480px)`，第一、第二张卡片采用“固定卡宽 + 明确 gap”计算，第三张卡片使用右侧锚点和正向纵向位置。
- 未修改 Vue、API、路由、购物车状态、商品排序或移动端布局。
