# 浅色 A+C 混合器物材质组件实施计划

## 目标

用户确认融合上一轮效果图 A 与 C：

- A：深玉承重边、古铜细节点缀、明确的组件状态层级；
- C：月白釉面主体、深玉侧轨、温润高光与器物质感。

最终方向为“月白釉面 + 深玉侧轨 + 单一古铜嵌线”，不再继续堆叠厚重双框。

## 范围

- 浅色卡片：馆藏、内容、预约、商城、账户、后台工作区；
- 共享按钮、搜索框、复选框、分段/日期/时段控件、状态徽标和原生字段；
- default / hover / focus-visible / pressed / disabled / loading / error / success；

- 深色主题保持既有视觉契约。

## 实施方式

1. 以 `light-ui-material-depth.css` 为唯一浅色材质后置层，将“厚双框”收敛为单一釉面主体、连续深玉下/侧轨和必要时出现的古铜 active/focus seam；
2. 卡片使用 `background` 分层与 inset shadow 表达釉面和切面，使用方向性 `box-shadow` 表达底部器座，不再用多重 `outline` 制造纸片边框；
3. 按钮使用实色深玉/月白釉面，按压仅改变高度与承重阴影；搜索框和原生字段使用浅凹槽，复选框使用釉面方体；
4. 保留已有响应式、减少动态、减少透明度、高对比度和强制颜色降级；
5. 用 Docker 真实页面截图复核 `/explore`、`/appointment`、`/shop` 和移动端，重点检查边缘、按钮层级、搜索框和横向溢出。

## 验收标准

- 卡片边界不再呈现纸片式单薄线框，也不出现厚重的双重描边；
- 深玉侧/下轨在浅色页面中可感知但不抢夺内容，古铜仅作为 focus/active 细节；
- 主按钮有明确实体重量，次按钮与输入控件有稳定的釉面/凹槽层级；
- 键盘焦点、禁用、错误、成功和减少透明度/强制颜色分支可识别；
- 前端类型检查、全量测试、生产构建、页面映射审计、Docker HTTP 与实页截图通过；
- 不提交 Git commit，保留工作区既有未提交改动。

## 风险与未验证项

- 生成效果图不能替代 CSS 实际渲染；最终以 Docker 实页和计算样式为准；
- 实体手机、触控笔、Windows 系统强制颜色、真实慢网和后台真实管理员 CRUD 仍需现场补验。
