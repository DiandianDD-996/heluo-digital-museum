# 前端视觉升级概念样稿

## 目标

在不修改生产前端、不改变业务流程的前提下，为河洛数字博物馆提供三套可直接比较的高保真视觉方向，供正式升级前选择。

## 关联需求

- F-01：公开首页与内容展示
- F-02：馆藏浏览与检索
- F-05：数字展项展示
- N-03：双主题、响应式与可访问性体验

## 影响范围

- 新增：`docs/design-prototypes/2026-09-26-upgrade/` 下的静态概念样稿与截图。
- 不修改：`frontend/src/`、路由、接口、数据模型、认证、支付、现有测试。

## 方案

1. 洛书九宫：以河图洛书作为首页和馆藏导航的信息架构。
2. 河洛长卷：以洛河及器物年代为连续叙事结构。
3. 器物剧场：以器物为主角的暗室聚光数字展厅入口。

每套样稿均使用现有本地图片，提供桌面与手机布局；动效仅由交互触发，并为减少动态偏好提供静态呈现。

## 验收标准

- 三套 HTML 可独立打开并在 1440px、390px 宽度正常展示。
- 图片无可见留边；文本、按键和焦点状态清晰；不存在横向溢出。
- 在 `prefers-reduced-motion: reduce` 下无自动持续动画。
- 概念阶段不触碰生产代码、不改变需求追踪的完成状态。

## 风险

- 概念字体采用浏览器本地字体栈，正式产品若引入字体文件，需另行评估许可、子集化和包体预算。
- 长卷横向叙事与剧场式全屏体验需要在实施阶段补充键盘、屏幕阅读器与移动端测试。

## 验证结果

- 已新增 3 套方向、共 7 个静态 HTML 页面（总览页 + 每套首页与馆藏页），全部使用项目现有本地媒体。
- 静态引用校验通过：7 个页面的全部图片相对路径均指向存在的 `frontend/public/media/editorial/` 文件。
- 静态结构与范围检查通过：`git diff --check` 无空白错误；新增文件均在 `docs/` 下，未修改 `frontend/src/`。
- 未执行浏览器截图、控制台、视觉回归或 390px/1440px 实机页面验证：预览服务器因目录暴露策略未获本轮权限。样稿包含对应响应式规则，但该项需要在用户浏览器中打开后或获准专用静态服务器后完成。
- 未运行生产前端测试、类型检查或构建：本概念阶段没有改动生产代码，现有历史验收状态不变。
