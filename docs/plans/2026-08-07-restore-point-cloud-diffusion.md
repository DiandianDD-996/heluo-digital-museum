# 恢复点云扩散解构动画

## 目标

- 恢复实体进入点云时清晰可见的空间扩散与回收过程。
- 保留上一轮已经实现的连续速度曲线、任意时刻反向和 shader 预热。
- 保持既有点云颜色、深度遮挡、点数分档和相机构图不变。

## 关联需求

- F-05：数字展项应提供可辨识、有表现力的点云解构观察。
- N-03：桌面与移动端动画连续，无跳帧、闪烁和布局溢出。
- N-06：关键动画幅度和双向连续性具有专项测试。

## 影响范围

- `frontend/src/components/ThreeExhibitViewer.vue`
- `frontend/src/components/ThreeExhibitViewer.spec.ts`
- `docs/plans/2026-08-06-exhibit-transition-curve-polish.md`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

不修改 palette、shader 调色、`depthWrite`、GLB、点数、相机、API 和路由。

## 实施步骤

1. 将首次进入点云的空间弧线从上一轮过度收敛的 `28%` 恢复到原动画的 `78%` 扩散幅度。
2. 将首次解构节奏从 `1.25s` 恢复到 `1.8s`，让扩散和回收有足够可见时间。
3. 继续使用单一 `smootherStep + sin²` 连续曲线，不恢复旧四段式速度断点。
4. 保留按剩余距离缩短的返回与反向切换，以及减少动态模式的 `220ms` 淡变。
5. 增加扩散中点幅度、扩散中途返回、返回途中再次进入点云的专项测试。

## 验收标准

- 动画中点粒子聚合进度约为 `.22`，形成明确空间扩散，而不是贴在模型表面淡入。
- 动画结束粒子完整回收到鼎的表面点云，`mix=1/gather=1`。
- 扩散中途返回、返回途中再次进入点云时，下一帧位置和透明度连续。
- `1433x746` 与 `390x844` Canvas 唯一且为 `running`，无横向溢出或控制台新增错误。

## 风险

- 大幅扩散会暂时降低鼎的实体轮廓密度；通过对称连续回收和固定完成态确保最终点云清晰。
