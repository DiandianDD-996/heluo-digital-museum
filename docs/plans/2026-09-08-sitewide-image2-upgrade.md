# 全站实页参考图驱动升级

## 目标与关联需求

按用户指定的 soloapi-image2、impeccable、frontend-design、apple-design，先生成与当前页面对应的优化提示词，再用当前实页截图编辑生成效果图，最后依据效果图升级前端。覆盖 14 类路由、浅深主题及桌面/移动布局。关联 F-01 至 F-14、N-03/N-06。

## 范围与约束

- 复用当前工作树、河洛纸墨设计系统、系统字体和真实媒体；保留现有未提交修改。
- 公开内容突出文物；预约/商城/账户优先任务；后台保持紧凑管理结构；3D 保留真实运行时。
- SoloAPI 仅用于用户明确要求的参考图生成，不能将 UI 效果图作为整页背景替代可交互 DOM。
- 不变更后端接口、数据结构、权限、支付方式；不提交、推送或发布。

## 影响文件

提示词及对应表保存于 docs/design/2026-09-08-sitewide-image2/；截图和效果图保存于 artifacts/sitewide-image2-upgrade/。前端修改范围以参考图审查后确定的页面和共享样式为准，完成时补充清单。

## 步骤

1. 核对路由、现有样式、运行环境与生成器配置。
2. 构建当前工作树，在隔离本地 API 上获取真实页面；记录桌面/移动与双主题截图、当前页面内容和错误。
3. 写入各页特定的布局、内容、交互、响应式与不可变约束；输入对应实页图片生成参考图。
4. 检查输出文件及视觉质量，按图逐页实现，保持主题一致及业务状态完整。
5. 运行类型检查、单测、生产构建、浏览器全站截图及关键业务流程，审查差异并同步状态文档。

## 验收与风险

- 14 类路由均有实际截图、专属提示词及真实生成结果；失败明确记录。
- 桌面/移动双主题可读、无内容重叠及横向溢出；图片真实加载，3D 非空且可操作。
- 登录、预约、模拟下单支付和后台关键流程通过本地浏览器验证。
- 生图可能失真或改动文字，实施时必须回到真实内容；外部生成失败不得报告成功。
- 本地隔离数据为验收数据，不能称为线上现状；实体设备与线上发布不在本轮自动完成范围内。

## 比例与素材质量门禁（用户补充）

- 生成输入必须保留原始宽高比；网页截图使用 `deviceScaleFactor: 2`，桌面/手机分别输出，并用自然滚动的连续截图补充长页内容。
- 效果图不得把多视图挤压成拼贴、不得拉伸手机画面或压缩长页面；每张图只表达一个页面视图。
- 真实器物素材逐张检查主体完整、无明显变形、无水印文字、纹理可辨、尺寸可用于目标卡片；不通过则标记不可用并保留原素材。
- 用户补充：所有页面效果图均需浅色与深色两套；首页重新提高视觉升级幅度，先分别生成两套桌面效果图审查后再进入实现。
