# Product Design 审查问题修复计划

## 目标

根据 2026-08-14 Product Design 审查结果，修复当前前台页面中优先级最高的 5 个体验问题：深色 Explore 阅读卡可读性、移动端账户入口与商城登录回跳、移动端 3D Dock 被底部导航遮挡、预约步骤与日期横向滚动可理解性、桌面端单条搜索结果的留白。保持现有 API、路由、鉴权、预约/购物车/模拟支付状态机和 Three.js 生命周期不变。

## 关联需求

- `F-01` / `F-02` / `F-03`：馆藏浏览、搜索和详情内容仍可正常访问。
- `F-05`：3D 展厅的实体/点云模式、视角切换和失败降级行为不变。
- `F-06` / `F-08` / `F-09`：预约、账户登录和购物车入口继续沿用后端权限边界，并保留未登录后的返回位置。
- `F-12` / `F-14`：中英文文案和深浅主题都需要有对应的可读样式。
- `N-03` / `N-06`：桌面与手机端无关键遮挡或横向溢出，类型检查、测试和构建可复现。

## 实施步骤

1. 为深色主题的 Explore 延伸阅读卡单独定义深色表面、标题、摘要和操作色；保留浅色主题的现有层级与卡片几何。
2. 在移动端 Header 保留可见的登录/个人中心入口；商城未登录加购时带上安全的 `returnTo`、意图和商品 ID，登录成功后回到商城并恢复一次加购意图。
3. 让 3D 展项移动端的 Dock 内容避开固定底部导航，隐藏原生横向滚动条但保留可滚动能力，并区分“显示模式”按钮与导览中的点云步骤文案。
4. 提升预约移动端步骤文字和当前状态的可见性，日期带使用无视觉滚动条、吸附和可理解的选中态，不改变日期/时段选择规则。
5. 为单条搜索结果增加单列宽度约束/横向信息布局，消除桌面端右侧大面积空白；移动端继续单列堆叠。
6. 深色 3D 展厅仅压暗透明 WebGL Canvas 后的 DOM 厅堂背景，保留青铜器材质高光、点云/实体模式和相机交互；避免后加载的浅色参考背景在主题切换后透出。
7. 首页“河洛故事”策展卡改用已有、已检查的深墨石板素材，而不是把浅底展品封面压暗；中英文卡片共用该稳定媒体源。
8. 运行专项测试、类型检查、全量测试、生产构建和 Docker 页面回归；在 `1440x900`/`390x844` 下检查深浅主题、关键交互、无横向溢出和固定导航遮挡。

## 验收标准

- 深色 `/explore` 阅读卡的标题、摘要、元信息与操作文字达到清晰可读的对比度，且浅色 `/explore` 不被破坏。
- `390x844` 的 Header 有可操作的“登录/个人中心”入口；未登录点击商城加购会进入 `/login`，并携带仅限站内路径的回跳信息和商品意图。
- `390x844` 的 3D 展项 Dock、视角缩略图和说明不被固定底部导航覆盖；模式/导览文案不再造成重复歧义，字号不低于约 `12px`。
- `390x844` 的预约步骤显示当前阶段/已完成阶段，日期带可横向滑动但不显示原生滚动条，日期与时段选择仍可完成。
- `1440x900` 单条搜索结果使用受控的内容宽度/横向卡片，不再只占左侧窄列；多条结果和移动端布局保持原行为。
- 深色 `390x844` 3D 展厅的环境画面为低亮度墨黑铜色，青铜鼎本体仍清晰可辨，且透明 Canvas、点云/实体切换和 Dock 交互不回归。
- 深色首页“河洛故事”卡不再出现浅色石板底图，石板与其余两张器物卡使用同一类深墨展陈环境。
- `pnpm typecheck`、相关测试、`pnpm test`、`pnpm build` 以及 Docker 实页回归结果如实记录；失败项不标记为完成。

## 风险与验证

- 登录回跳必须使用现有 `safeReturnTo` 约束，禁止把查询参数变成外部跳转地址。
- 商城自动恢复加购只允许对查询中存在且当前 API 返回的商品执行一次，避免刷新重复加购。
- 3D 页面是动态 Canvas，除 DOM 几何外需确认页面加载、模式切换、视角切换和资源失败降级未回归。
- 当前工作区已有大量未提交改动；最终只审查本计划涉及文件的 diff，不处理无关文件。

## 验证结果

- `pnpm exec vitest run src/assets/darkThemeCohesion.spec.ts`：`17` 项通过；新增契约锁定深色 3D 厅堂的低亮度背景、背景图和居中几何。
- `pnpm typecheck`、`pnpm test`（`33` 个文件 / `153` 项）和 `pnpm build` 通过。构建保留既有 VueUse `PURE` 注释与 Three.js 大分包警告。
- Docker 以前端当前代码重建；`http://localhost:8088/` 与 `/api/v1/health` 均返回 `200`，健康数据为 `UP`。
- 应用内浏览器在 `390x844` 复核深色 3D 展厅：无横向溢出，底部导航已隐藏，Canvas 仍为透明；实体与点云模式均可切换，应用级 console error 为 `0`。保留既有 Three.js `X4122` 浮点精度 warning。
- 审查证据：`docs/design/audit/2026-08-14-dark-mode/` 下保存首页、Explore、商城、实体展厅和点云展厅的实际截图。
- 首页策展卡修复：复用已在仓库且已检查的 `explore-river-map-stone-user-v2.webp` 深墨石板素材，因此无需额外生成图片；中英文卡片均切换到该素材。`HomeView.spec.ts` 2 项、类型检查、生产构建和 Docker 首页/素材 HTTP `200` 通过；`1433×898` 深色实页无横向溢出，截图见 `docs/design/audit/2026-08-14-home-card-media/`。
