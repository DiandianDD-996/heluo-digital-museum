# 参考图式深色首页精修计划

## 目标

在不改变路由、API、权限、预约、商城、模拟支付、主题持久化和 Three.js 状态机的前提下，按用户提供的参考图精修河洛数字博物馆深色首页：建立深墨展馆画布、象牙白编辑标题、古铜金重点、低透明玻璃路线板和紧凑策展卡片的清晰层级，同时保持浅色主题与移动端可用性。

## 关联需求

- F-14：前后台可切换并持久化深色主题。
- A-01：前台图片素材可追溯且适合 Web 加载。
- N-03：桌面和移动端无关键横向溢出，操作与文字可读。
- N-06：前端类型检查、测试和生产构建通过。

## 影响范围

- `frontend/src/views/HomeView.vue`：补充首屏主入口并加强路线区语义。
- `frontend/src/assets/main.css`：收口首页深色画布、首屏比例、标题、路线板、策展带、导航和响应式样式。
- `frontend/src/test/HomeView.spec.ts`：锁定主入口、三条业务路线和三张策展卡结构。
- `frontend/src/assets/darkThemeCohesion.spec.ts`：锁定参考图式首页深色层级契约。
- `design.md`：记录深色首页的象牙白、古铜金、深墨玻璃和素材使用约束。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：记录实施和验证结果。

## 实施步骤

1. 对照参考图和当前生产首页，确认深色首屏、导航、路线板与策展带的主要差距。
2. 复用现有 `museum-corridor-dark-image2.webp` 夜间馆廊素材，不重复生成相同资产。
3. 补充首屏探索主入口，优化深色标题、环境遮罩、路线玻璃、导航和下方卡片层级。
4. 补齐 `980px` 与 `760px` 断点，确保移动端标题、主入口和路线板不重叠。
5. 运行专项测试、全量前端测试、类型检查、生产构建、差异检查和响应式页面门禁。
6. 重建本地前端服务，复核深浅主题桌面和移动首页的视觉、控制台与横向溢出。

## 验收标准

1. 深色首页首屏在第一视口呈现深墨展馆、中央文物、象牙白标题、古铜金重点和右侧低透明路线板，主次关系与参考图一致。
2. 首屏主入口可直接进入 `/explore`；三条路线仍分别进入馆藏、数字展厅和预约。
3. 下方策展带使用紧凑、可扫描的深色卡片层级，三张文物卡和路线图均保留。
4. 浅色主题不被深色覆盖污染；主题切换与刷新持久化行为不变。
5. `1440x900`、`1672x941`、`390x844` 下无关键横向溢出、文字遮挡或按钮裁切；键盘焦点和减少透明度降级仍可用。
6. 前端相关测试、类型检查、生产构建和 `git diff --check` 通过。

## 风险

- `main.css` 包含多轮历史视觉规则，本轮只在现有主题尾部增加明确的首页作用域覆盖，避免改动业务页面或重排全文件。
- 夜间素材中的中央青铜鼎比参考图克制；优先通过背景取景、对比和周边层级强化主体，不使用会破坏透视关系的独立图片叠加。
- 首屏加高或标题放大会挤压移动端路线板，因此移动断点必须使用独立的纵向节奏与背景位置。
