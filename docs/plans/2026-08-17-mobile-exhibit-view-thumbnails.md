# 移动端 3D 视角缩略图完整显示

## 1. 目标

修复 `/exhibits/heluo-bronze-ding-3d` 在 391–760px 移动视口中“俯视”视角缩略图被轨道裁切的问题，让五个视角入口在常见 412/430px 宽度下首屏完整可见。

关联需求：`F-05`、`F-12`、`N-03`、`N-06`。

## 2. 影响范围

- `frontend/src/assets/route-exhibit-detail-legacy.css`
- `frontend/src/assets/ExhibitMobileViewLayout.spec.ts`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

不修改 API、路由、鉴权、3D 相机/模型、预约/订单状态机或其他页面布局。

## 3. 实施方案

- 在 391–760px 增加专用响应式规则：视角轨道使用紧凑间距，五个按钮使用 `flex: 1 1 0` 和 `min-width: 0` 等分可用宽度。
- 该区间关闭轨道横向滚动，避免最后一个视角在初始状态落到卡片外；按钮高度、图片高度和文字保持现有触控尺寸约束。
- 390px 及以下继续保留最小 68px 按钮和横向滚动，以保证窄屏触控目标不被压缩。

## 4. 验收标准

- 430px 与 412px 移动视口下，五个视角按钮均完整落在 `.view-switcher > div` 可视矩形内，轨道无横向滚动需求。
- 390px 及以下视口仍保留可横向滚动的稳定按钮尺寸。
- 视角按钮点击、五个预设相机和主题样式不受影响。
- 相关专项测试、类型检查、生产构建和 `git diff --check` 通过。

## 5. 风险与验证

- 该页面 CSS 含历史层叠规则，需检查最终构建后的计算矩形；源码测试不能替代真实浏览器回归。
- 本轮不宣称实体手机触控、系统强制颜色和中低端 GPU 长时间运行已验收。

## 6. 验证结果

- 根因复现：线上 430px 视口中轨道 `clientWidth=364`、`scrollWidth=398`，五个 `72px` 按钮加间距超出可视宽度，最后的“俯视”入口初始显示不完整。
- 本地 430px 与 412px 实页修复后，轨道分别为 `364/364px`、`346/346px`，五个按钮均完整落在轨道内；页面无横向溢出。390px 保留 `68px` 按钮和 `overflow-x:auto`，轨道 `330/372px`，继续支持窄屏横向访问。
- 本地 430px 实页点击“俯视”后 `aria-pressed=true`，按钮可用，浏览器控制台 `warning/error` 为 `0`。
- 专项测试 `2` 文件 / `8` 项、前端全量 Vitest `46` 文件 / `256` 项、类型检查、生产构建、构建预算、`qa:pointer-pages 32/32` 与任务文件 `git diff --check` 通过。
- 本轮未覆盖发布 PocketBay；线上仍为既有 release `530`，需在后续发布后复核线上 430px 页面。
