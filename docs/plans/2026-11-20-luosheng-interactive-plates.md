# 洛笙图版交互

关联 LS-02、LS-03、LS-04、LS-06。调整青铜鼎展签现有观察区。

保留标题宋体、讲解黑体，以及纸色 #faf8f2、青绿 #246452、石墨 #242321、青灰 #a9c2b5、古铜 #c9ad87。左侧放讲解与追问入口，右侧放可操作的图版。古铜取景圈只标识游客正在看的部位。

- 鼎耳图版提供左右两个观察点，支持点击和键盘操作。图版不可用时保留文字提示。
- 三足支持侧视和背视对照，同一位置切换图版并读出对应观察线索。
- 纹样可展开局部观察提示。实时预览中可将当前看点的推荐问题带入输入框，由游客确认发送。
- 右上角沿用原有回纹轮廓，加细刻线和铜色高光。进入展签、切换看点或选择观察点时掠过一次，减少动态效果模式下保留静态纹理。
- 验收覆盖手机与桌面、深浅主题、图版失败以及看点和问题的接续。

## 验证记录

- Chrome 从馆藏搜索进入青铜鼎，验证 320、390、768、1440 像素的深浅双主题共八组布局，以及两组触控模拟。覆盖双耳操作、侧背视切换、纹样提示、3D 往返及图版失败退路。
- 减少动态效果模式保留静态回纹。普通动效下补测 1440 像素深色和 390 像素浅色的扫光触发、问题预填、输入框聚焦及等待游客发送。
- 前端 507 项测试通过。类型检查、生产构建、首屏和配乐资源预算通过。实体设备、系统读屏与正式发布待验。
