# 2026-08-15 Explore 官方博物馆官网质感精修计划

## 目标

在不改变 `/explore` 的 API、路由、搜索、分类、分页和详情跳转逻辑前提下，将当前页面从“效果图式展示页”收敛为可信、安静、可持续浏览的官方博物馆馆藏页。重点处理桌面版心、区块留白、卡片边界、媒体舞台、筛选按钮、操作文案和浅深主题协调性。

## 关联需求

- `F-01`：游客浏览已发布馆藏和文章。
- `F-02`：游客按关键词搜索馆藏和文章。
- `F-03`：游客进入馆藏或文章详情。
- `F-12/F-14`：中英文和浅深主题共享一致的信息层级与交互。
- `N-03/N-06`：桌面和移动端无横向溢出，控件焦点、减少动态和强制颜色降级可用。

## 基线问题

- 发现区之后的筛选、馆藏、主题脉络和阅读区在桌面端接近全屏铺满，缺少官方内容站常见的稳定正文版心。
- 筛选条与馆藏标题之间仅约 `9px`，区块节奏过急；卡片网格间距则接近 `38px`，疏密关系不一致。
- 重点馆藏卡约 `486px` 高，信息区操作被推到底部，形成明显无效空白。
- 浅色阅读卡的媒体四周形成较厚套卡边缘，深色卡片阴影和浮起感偏重。
- “馆藏器物”同时作为眉题和标题，操作文案自带箭头又叠加 CSS 箭头，出现“→ →”。

## 视觉合同

- 首屏发现区保留宽画幅山水构图；其后的功能与内容区使用 `1320px` 最大版心和随视口增长的桌面边距。
- 重复卡片统一 `8px` 圆角、单层 `1px` 边界、克制接触阴影和清楚的媒体/正文分隔；不新增玻璃、渐变胶囊或嵌套卡片。
- 筛选条是紧凑分段控件：外层与按钮形状统一，default/hover/selected/focus 状态清楚，触控目标不小于 `44px`。
- 重点馆藏卡桌面高度控制在约 `410–460px`，文案成为一个完整信息组，不把主操作孤立到大面积空白底部。
- 阅读媒体与卡片顶部齐平，正文使用固定、可读的排版层级；卡片 hover 仅 `-2px`，按压与减少动态保持现有合同。
- 所有新增颜色、边界和阴影引用已有 `--theme-*` 与 `--collection-*` 令牌；浅深主题共用几何。

## 影响文件

- `frontend/src/views/ExploreView.vue`：去除重复眉题和操作文案内置箭头，不改业务状态与数据请求。
- `frontend/src/assets/explore-discovery-reference.css`：扩展为 Explore 末级页面样式所有者，统一版心、留白、卡片、筛选、分页和响应式细节。
- `frontend/src/views/ExploreReferenceLayout.spec.ts`：增加版心、卡片圆角、筛选状态、箭头和无障碍降级合同。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：完成后记录真实验证结果。

## 实施步骤

1. 恢复“发现区宽、正文区收窄”的两级版心，并重新分配筛选条与内容标题的垂直间距。
2. 统一重点馆藏、目录馆藏、阅读与搜索结果卡的边界、圆角、阴影和媒体分隔。
3. 收紧重点馆藏高度和正文组，移除阅读卡媒体外层套卡边距。
4. 统一筛选、分页、文本操作的 hover/focus/disabled 状态；修复重复眉题与重复箭头。
5. 为 `760px` 以下恢复移动端全宽内容，复核中英文、浅深主题和可访问性降级。

## 验收标准

- `1440 x 900` 下首屏保持宽画幅，后续正文最大宽度不超过 `1320px`，馆藏区左右边距清楚且一致。
- 筛选条与馆藏标题、标题与卡片之间的间距形成明确层级；卡片网格间距稳定在约 `24–28px`。
- 重复卡片圆角不超过 `8px`，媒体和正文只有单一可见外边界，浅深主题无厚重发光或套卡感。
- 所有“查看器物 / 阅读文章 / 阅读详情”只显示一个箭头；中英文无截断或异常换行。
- 搜索、清除、分类、分页、详情跳转和返回保持可用；桌面、移动端无页面级横向溢出，控制台无新增错误。
- Explore 专项、前端全量测试、类型检查、生产构建、`git diff --check`、正式 Docker 页面与 health 通过。
