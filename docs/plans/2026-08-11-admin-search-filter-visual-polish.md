# 后台导航、探索搜索与筛选视觉修复

## 目标

根据真实浏览器标注，修复深色后台导航卡偏绿、探索页搜索框双层玻璃以及分类筛选按钮底部溢出，同时保持现有 API、路由、权限、业务状态机和 Three.js 逻辑不变。

## 关联需求

- F-01 / F-03：公开内容浏览、搜索和分类筛选保持可用。
- F-12 / F-13 / F-14：内容与运营后台保持既有权限和任务工作台结构。
- N-03 / N-06：深色视觉统一、响应式、焦点可见和至少 `44px` 触控目标。

## 影响范围

- `frontend/src/components/MuseumSearchField.vue`
- `frontend/src/assets/main.css`
- `frontend/src/test/SharedUi.spec.ts`
- `frontend/src/assets/darkThemeCohesion.spec.ts`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

## 实施步骤

1. 将共享搜索框的玻璃材质挂到唯一控件层，外层表单只负责标签、状态和布局。
2. 将分类筛选容器改为自适应高度，父容器与按钮共同满足 `44px` 触控合同。
3. 为深色后台导航增加中性石墨表面、暖古铜当前态和清晰的 hover/focus 层级。
4. 增加组件与 CSS 契约测试，运行前端测试、类型检查、构建、页面门禁和差异检查。
5. 重建前端容器，在真实浏览器复核 `/admin` 与 `/explore`。

## 验收标准

- 后台“内容 / 运营”两张导航卡不再以青绿色为大面积底色，当前项只用低面积暖古铜提示。
- 搜索区域只有一个完整的玻璃控件边界，标签和错误信息不被第二层卡片包裹。
- 分类筛选按钮不超出导航底边，焦点环不被裁切，桌面和移动端均可操作。
- 不改变搜索事件、后台路由、权限、API 或业务数据。

## 风险与验证

- `main.css` 存在多轮历史主题规则，本轮使用组件专属末端规则收口级联，并以契约测试防回归。
- 需验证窄屏横向滚动仍保留且不会裁切焦点；实体手机和系统强制颜色模式另行记录为未覆盖项。
