# 数字展项实体与点云切换流畅度修复

## 目标

- 消除首次进入点云时的 shader 临时编译卡顿。
- 让实体与点云的双向切换使用连续速度曲线，并支持动画中途反向操作。
- 保留当前点云构图、深墨玉/古铜金配色、点数分档、相机和业务接口。

## 关联需求

- F-05：3D 展项支持稳定、可重复的实体/点云观察。
- N-03：桌面与移动端交互连续，无明显卡顿、闪烁或布局溢出。
- N-06：减少动态、性能降级和可访问状态保持有效。

## 影响范围

- `frontend/src/components/ThreeExhibitViewer.vue`
- `frontend/src/components/ThreeExhibitViewer.spec.ts`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

不修改 GLB、API、路由、权限、数据库、点云配色和相机预设。

## 根因

1. 点云对象初始为 `visible=false`，完整首帧的 `compileAsync` 不会编译点云 `ShaderMaterial`，首次点击时才触发 shader 编译。
2. 旧反向切换只保存透明度，没有保存粒子的空间聚合进度；解构中途切回实体时会把 `uProgress` 直接重置为 `1`，形成位置跳变。
3. 旧实现没有同时保存透明度和粒子空间聚合进度；解构中途反向时，粒子位置会瞬间重置并造成轮廓跳变。
4. 四段旧曲线包含长时间停驻和非对称 `easeOut`，阶段交界虽然数值连续，但速度变化明显。

## 实施步骤

1. 在加载遮罩下临时显示零透明度点云，使实体与点云 shader 一起预编译，首屏渲染前恢复正确模式。
2. 用统一的 `visualMix + cloudGather` 当前帧状态记录透明度和粒子空间位置。
3. 双向切换从当前状态创建可中断过渡，使用端点速度为零的 `smootherStep` 曲线。
4. 将解构阶段改为连续的揭示、展开、回流、归位，不再保留静止平台。
5. 实体只改变透明度并保持原始深度写入属性；点云保留深度写入，避免前后表面粒子透叠破坏深墨玉与古铜金层次。
6. 增加 GPU 预热和中途反向切换测试，再执行工程、Docker 和双尺寸浏览器回归。

## 验收标准

- 首次点击点云时不再发生 shader 编译峰值或短暂停顿。
- 解构中途点击实体，下一帧的 `uProgress` 从当前值连续变化，不瞬间跳到 `1`。
- 点云与实体完成双向切换后，实际模式、按钮状态和 Canvas 渲染状态一致。
- 快速连续往返不会重载 GLB、重采样点云、闪白或卡死。
- `1433x746` 与 `390x844` Canvas 非空，无横向溢出和控制台新增错误。

## 风险

- 加载阶段会额外预编译一个点云 shader，但发生在遮罩后，换取首次交互稳定。
- 同时绘制实体和点云仍会增加过渡期 GPU 开销，因此保留现有点数和低帧率降级策略。
