- `F-12`：票券标题、路线站名和摘要标签继续支持中英文。
- `F-14`：浅色与深色主题都保持可读且不互相污染。
- `N-03/N-06`：保留响应式、键盘可达性、减少动态/透明度和强制颜色降级。

## 视觉合同

- 参考图：`docs/design/audit/2026-08-15-appointment-ticket-reference-rebuild/reference-user.png`，用户提供，`1122 x 1402` PNG，仅作视觉合同，不作为运行时背景或生产 UI 图片。
- 分层素材：用户给出的 ChatGPT 分享页包含无文字票券底板、路线段、路线/摘要底板、徽章、山云、水纹和馆舍剪影。浅色桌面票券允许使用经裁切压缩的无文字底板与路线段；任何标题、站名、日期、时段、人数和控件仍由真实 Vue DOM/SVG 渲染。
- 桌面票券采用暖白纸面、双层古铜细边、实体阴影和不超过 `8px` 的内层圆角；不引入纸片堆叠、玻璃拟态或渐变装饰球。
- 顶部为 `VISIT TICKET`、大号预约信息标题和中央山云纹样分隔线。
- 路线面板保持约 `2:1` 比例，包含低权重水纹和馆舍剪影；入口广场、核心展厅、文创空间三站均由可访问 SVG 文本承载，核心展厅为唯一放大的深玉主徽章。
- 摘要始终显示参观日期、参观时段和参与人数。未选时段时显示真实占位提示，不自动选择或伪造可预约时段。
- 人数使用 `Minus / 数字 / Plus` 步进控件，范围限制为 `1–30`；保留可提交的原生数字输入值和无障碍名称。
- 联系人字段、提交按钮和错误/成功状态保留在票券摘要之后，不能删除或改变预约状态机。

## 验收标准

- 在目标桌面视口中，预约信息呈现为一张完整票券：标题、分隔、路线和摘要连续可见，而不是路线图与裸字段脱节。
- 路线面板的核心展厅显著大于两端站点；三站、顺序和中英文文本未被截图图片烘焙或裁切。
- 未选择时段时摘要仍可见且不展示伪数据；人数按钮不可突破 `1–30`，键盘和原生数值输入仍可用。
- 不改变 API、路由、鉴权、时段选择、预约提交、幂等键、字段校验、预约状态机或移动 BottomSheet。
- 桌面浅色参考对照、桌面深色、英文、`390 x 844` 移动端均没有页面级横向溢出；强制颜色和减少透明度下信息仍可辨识。
