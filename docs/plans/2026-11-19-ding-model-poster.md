# 青铜鼎 3D 启动封面重拍

- 目标与追踪：F-05、N-03、N-06。只替换 v5.5 青铜鼎在启动 3D 前与加载失败时共用的预览封面，并同步同一 URL 的三个响应式变体。
- 方案：从项目重制 GLB 原位取景，使用略高的四分之三视角和柔和侧光，移除原图中的金盘与硬背景；透明 WebP 让现有深浅主题承接背景。数字重制参考 Cleveland Museum of Art 1962.281，不是原物照片；来源延续项目 v5.5 资产记录。
- 不改模型、API、数据库、展厅列表独立策展配图、视角按钮图或洛笙图版。沿用旧 URL 保持数据库兼容，旧版资源可从 Git 查看。
- 验收：器物轮廓在深浅主题及桌面／窄屏不截断、封面可正常解码、未点击时不请求 GLB；核对资源预算和生产导航。正式部署需刷新原 URL 的缓存。

## 实施结果

- 从 `frontend` 运行 `node scripts/render-luosheng-plates.mjs http://127.0.0.1:5197 --poster`，得到 980 × 1180 透明主图（62,740 B）及 320／640／960 像素宽变体（16,242／37,684／60,714 B）。保留历史文件名，不修改 API 数据。
- `node scripts/ding-poster-check.mjs`：1440 和 390 像素宽、深浅色共四组使用真实 API 的 Chrome 触控模拟通过。手动启动路径中图片成功解码且完整适配，不提前请求 GLB；窄屏截图确认返回按钮没有压住鼎耳。桌面普通鼠标设备仍遵循原自动启动规则。
- 479 项单测、含类型检查的生产构建、构建资源预算、生产预览公开导航及洛笙隔离门禁通过。最终主图与构建产物散列一致。未重新部署、未跑真机或重新测试实体运镜。
