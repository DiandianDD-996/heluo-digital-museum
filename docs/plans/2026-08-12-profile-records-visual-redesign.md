# 个人中心页面规划与预约/订单记录视觉重设计

## 目标

重做 `/profile` 的页面规划、账户信息、预约记录和订单记录真实 DOM，解决当前复用登录页整屏背景导致媒体被放大裁切、记录卡片缺少层级、英文状态直出、桌面/移动布局失控的问题。参考输入：用户提供的个人中心截图 `C:\Users\Jie\AppData\Local\Temp\codex-clipboard-653a52fc-cca6-4e59-ab33-4201d1a314bd.png`，目标是结构级和风格级收敛，不做像素复制。

## 范围与保持项

- 修改 `ProfileView.vue`、`ProfileAppointments.vue`、`ProfileOrders.vue` 和个人中心样式。
- 复用现有主题 token、`StatusBadge`、`FluidButton`、`InlineStatus` 与 API 请求。
- 不修改路由、接口、鉴权、预约取消确认、订单模拟支付、幂等键和数据模型。

## 视觉合同

- 桌面：稳定纸墨画布；顶部左侧为固定比例馆舍媒体索引与访客档案说明，主体工作区左侧账户资料、右侧预约/订单记录；不再使用登录页整屏背景。
- 移动：媒体缩为窄幅索引，标题和入口与媒体并列，资料与记录单列排列，卡片不横向溢出，操作保持至少 44px 触控高度。
- 浅色使用纸墨、暖灰和古铜操作色；深色使用深墨、石墨表面和低面积古铜，不把页面变成白色默认块。
- 状态使用中文语义标签，订单商品明细可换行，编号使用等宽数字便于扫描。

## 验收标准

- `pnpm typecheck`、相关 Vitest、生产构建通过。
- `/profile` 在桌面和 390px 移动视口无横向溢出，预约取消和待支付订单操作仍可用。
- 浅/深主题及减少透明度模式下文字、边界和状态均可读。
