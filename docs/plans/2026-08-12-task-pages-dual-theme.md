# 高频任务页双主题收敛计划

## 目标

在第一批主题基础层之上，完成预约、登录、个人中心、内容后台和运营后台的双主题迁移。任务页以清晰、稳定和高效率为主，不复用首页的电影感构图，不改变任何业务合同。

## 关联需求

- `F-06`：登录、注册、密码重置和个人资料。
- `F-08`：预约选择、提交与个人预约记录。
- `F-10`：个人订单与模拟支付记录。
- `F-12`、`F-13`：内容后台与运营后台。
- `F-14`：前后台浅色/深色主题一致性。
- `N-03`、`N-06`：响应式、无障碍和可维护性。

## 影响范围

- `frontend/src/assets/task-pages.css`：任务页语义表面、控件、焦点和降级规则。
- `frontend/src/assets/taskPagesTheme.spec.ts`：任务页主题契约测试。
- `frontend/src/main.ts`：在共享控件之后加载任务页主题层。
- `frontend/src/views/LoginView.vue`：增加登录任务页作用域类，不改变 DOM 结构与提交行为。
- `PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`：记录实施与验证结果。

## 实施步骤

1. 审计预约、登录、个人中心和后台中的直接颜色、透明表面和高优先级覆盖。
2. 预约页使用连续四步进度、清晰时段选择和明显高于画布的资料表单。
3. 登录表单改为近实色内容表面，补齐输入、自动填充、焦点和辅助操作状态。
4. 保留个人中心已完成的信息架构，只统一资料输入、退出操作和主题语义。
5. 后台收敛为侧栏、工具栏、工作区和记录区，减少装饰、玻璃和悬浮卡片感。
6. 运行专项、全量工程、Docker 和真实角色路径验证。

## 验收标准

- 浅色与深色保持相同布局和控件几何，主题切换不导致页面跳动。
- 登录和预约输入框至少 `44px`，与页面背景有明确层级，焦点可见。
- 预约日期、时段、资料、确认的当前状态清楚，成功与错误反馈使用语义状态。
- 个人中心预约/订单仍使用现有记录结构，取消、模拟支付和刷新行为不变。
- 后台保持紧凑工作台结构，表单、筛选、状态、记录和危险操作可扫描且可操作。
- 不改变 API、路由、权限、预约/订单状态机、模拟支付或 Three.js 行为。

## 风险

- `main.css` 含有多轮历史高优先级样式；本批通过末端任务页作用域迁移，不批量删除旧规则，避免影响公开媒体页。
- 工作区存在大量用户改动；只增量修改本计划列出的文件，不重置、不提交、不处理无关差异。
