# ADR-009 洛笙 v1 收敛：单件、单签、单界面

状态：已采纳，2026-11-22。依据：[评审与收敛方案](../plans/2026-11-22-luosheng-review-and-reset.md)。

## 背景

洛笙已具备扎实的事实安全内核（原文照录、引用重验、撤回与防回滚、冲突拦截、默认关闭），但放行门禁依赖不存在的独立馆方与正式试用，导致长期无法上线；卡片按审稿腔写作而被原样展示，模型在 v6 中只能逐字挑句，AI 价值不明显；开发态与生产态使用不同组件。AI 向导此前未经 ADR 纳入第一版范围。

## 决定

1. **范围**：洛笙作为第一版的可选扩展纳入范围，定位为作品集与演示站功能。v1 只服务青铜鼎（藏品页 + 3D 展项）与 ear / feet / motif 三个看点；不做平台化与第二件展品。
2. **签核**：用户本人是唯一内容负责人。卡片经用户审阅、提交到仓库并打 tag 即视为发布。保留文件指纹与最低版本校验；取消双签、独立馆方签章与多份候选快照。
3. **模型角色（接话 + 选卡）与大白话通道**：模型（`temperature=0`）只输出一句 ≤24 码点、不含事实的接话，以及本轮候选内的卡片编号、是否追加边界句、白名单动作。事实正文由程序从卡片 `spoken` / `boundary` 逐字拼接。接话未通过事实词黑名单即降级为确定性路径。模型关闭、超时或超额度时，回答与确定性路径逐字一致。青铜鼎页放开前端正则拦截，将大白话统一放行至后端交由 v7 语义选卡；后端生成并发由硬编码 `1` 改为可配置有界线程池（默认 `4`）。
4. **界面**：`LuoshengSiteGuide` 是唯一问答面板（升级为最近 5 轮轻量对话流），`LuoshengPreset` 是展签只读讲解；删除 `LuoshengPreview`。开关收敛为 `VITE_GUIDE_ENABLED`、`museum.guide.enabled`、`museum.guide.model-enabled`。
5. **外部服务**：批准使用 DeepSeek 进行离线摸底与演示站运行。密钥只经服务端环境变量注入；每日调用上限已定为 **`200` 次/天**（`museum.guide.daily-turn-limit=200`）。
6. **门禁**：采用方案 §8 的三档门禁（PR 级 / 里程碑级 / 发布级）。发布级要求均由用户本人可提供证据。

## 取代

- `2026-11-21-luosheng-smart-usable-master.md`：INT-2 取消；INT-4 概念展品冻结；INT-6 与 Phase C 由收敛方案 M5 与 §8 取代。
- `2026-11-21-luosheng-unified-visitor-guide-final.md` §14 待决事项：分别由本 ADR 第 4、3、5 条关闭。
- `2026-11-19-luosheng-acceptance.md` 的放行记录模板：由收敛方案 §8 发布级门禁取代。

## 后果

- 正面：门禁可达，可在约 8 个工作日内公开开启；口吻由卡片 `spoken` 决定，可以写得像人话；开发与生产体验一致。
- 代价：单人签核不具备真实机构的独立审核强度，对外说明需写明"演示项目，内容由项目作者依据公开馆藏记录整理"。接话句存在黑名单漏网风险，以 50 条人工抽查与一键关闭 `model-enabled` 兜底。
- 复核条件：若项目转为真实馆方部署，恢复独立签核与正式授权流程；若接话抽查连续两轮发现含事实，关闭模型接话。
