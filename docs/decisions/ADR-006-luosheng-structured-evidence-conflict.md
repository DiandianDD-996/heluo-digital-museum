# ADR-006：洛笙用结构化事实拦截证据冲突

状态：已用于内部试点；未启用正式卡包。

同一藏品、展项和语言下，馆方可给证据卡添加 `claim: { key, value }`，表示一个需保持一致的单值事实。由审核者统一键和值的口径；未标注卡兼容现有格式。字段存在但缺失有效键或值时，拒绝读取该卡包。

仅比较当前可见卡。一个键有多个不同值时，命中该事实的查询降为资料不足，不调用生成器；已引用该事实的答复在重新交付或回放前也会被拦截。不按相关度、卡片顺序或模型信心选择结论。草稿和撤回卡不参与比较，无关事实照常取证。

不采用模型自行比较正文：同义表述、年代精度和来源层级都可能造成误判。本规则只保护已规范标注的单值事实，不自动识别未标注的正文矛盾，也不替代内容签核。正式上线前仍需核验卡包标注与来源。
