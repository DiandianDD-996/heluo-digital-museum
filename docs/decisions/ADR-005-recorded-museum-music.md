# ADR-005：展馆录音配乐与现有声音总线

- 日期：2026-09-27
- 状态：已接受。用户认可三首R3试听作品，按既有音效优化范围接入。

## 背景

原背景音乐通过浏览器随机音序与简易合成器生成，难以表达用户要求的完整旋律、自然乐器与场景差异。用户经过三轮实际试听，认可由已核实CC0录音采样编排的R3作品。现有总开关、音乐/音效独立开关、音量档位、音乐避让与总线仍可复用。

## 决策

生产背景音乐采用三首已认可的预混音资源，首页、阅读和青铜展项按稳定路由/内容标识映射；无专属作品的页面复用相近场景并调整存在感，不宣称每件文物都有新曲。后台、异常及未匹配路由静音。

网页使用44.1kHz双声道128kbps MP3，保留无损母带及可复现制作脚本。首尾在离线制作中处理为自包含循环，浏览器使用原生循环，不依赖JavaScript定时跳转。资源位于既有公开 `/media/audio/music-r3/` 路径，沿用静态媒体访问与缓存规则。

用流式媒体元素播放，经MediaElementAudioSourceNode和每曲增益接入现有musicBus，再经duck和master输出。常态一个媒体，交接至多两个；不将数首完整音频同时解码为常驻AudioBuffer，不与原随机生成器并行运行。

已采用的R3作品自身包含空间和背景层，页面不再叠加原hall/bronze等持续合成环境音，避免额外固定音高改变已确认作品的和声和听感。原环境音引擎保留但当前路由不启用；短操作音效仍接受独立开关控制。

只有用户手势及偏好允许时才设置媒体资源并播放；同一曲目跨路由保持进度。隐藏页面暂停，重新可见后由新的用户手势恢复；加载失败降级为安静且不影响业务。用户关闭和新导航使旧异步播放结果失效。

## 取舍与边界

此方案以完整作品质量、内存和浏览器兼容性为优先，暂不引入多分轨自适应编曲。媒体元素的解码及原生循环精度受设备实现影响，需要实际浏览器、接缝与实体设备验收；技术检查不能代替主观耐听度判断。

素材采用明确许可的采样录音，不宣称古琴/箫实录或古代礼乐复原。未引入付费音源、外部音乐服务或新增前端依赖，不改变业务API、数据库与权限。
