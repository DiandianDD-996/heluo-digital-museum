# 河洛数字博物馆：首页同风格全站效果图提示词套装

> 用途：在网页版 ChatGPT 中上传当前首页截图后，逐张生成全站优化效果图。本文件只定义视觉方向，不改变现有 API、路由、权限、业务状态机或 Three.js 行为。

## 一、推荐使用方法

1. 新建一个网页版 ChatGPT 对话，上传首页截图，并把它命名为“首页参考图”。
2. 先粘贴“提示词 00：风格母版锁定”。这一步不生成图片，只让同一对话锁定设计语言。
3. 再按顺序一次只粘贴一个页面提示词。不要在一张图中同时生成多个完整页面。
4. 每个桌面页面先生成 `1440 x 900`、`16:10` 效果图；确认后，把“移动端追加词”附在原页面提示词末尾，另生成 `390 x 844` 效果图。
5. 若中途新开对话，重新上传同一张首页截图，并先粘贴提示词 00。
6. 生成图中文字若有错字，不要反复为文字重生成；重点确认布局、材质、层级、组件和交互状态，真实文字仍由 Vue DOM 实现。

## 三、提示词 00：风格母版锁定

```text
你现在是“河洛数字博物馆”全站 UI 视觉总监。请仔细分析我上传的“首页参考图”，把它作为后续所有页面唯一的视觉母版。现在先不要生成图片，只锁定以下设计合同，并回复“风格母版已锁定”。

【品牌与气质】
这是面向 18-30 岁年轻文化探索者的真实数字博物馆应用，不是营销落地页。整体气质是“夜间深墨展厅、河洛纸墨、当代东方数字策展”：克制、安静、具有文物真实质感和轻微数字感。避免传统宫廷红金、赛博朋克、游戏 HUD、奢侈品电商和通用 SaaS。

【首页母版中必须提取并复用的 DNA】
1. 近黑深墨、石墨灰、烟灰与深木色全局画布，暖象牙白标题，低面积古铜金强调；青玉绿只作稀疏点阵、焦点或成功状态，古铜金在单屏内不超过 5%。
2. 页面必须有四层可辨识深度：全局画布、次级环境/媒体舞台、内容表面、浮起控件，不能把所有区域做成同一块黑色。
3. 标题使用当代中文宋体/衬线体，正文使用清晰中文黑体/无衬线体；大标题自然换行，数据和编号紧凑。
4. 复用首页顶部导航：左侧圆形馆印与“河洛数字博物馆 / HELUO DIGITAL MUSEUM”，中间为“探索馆藏、数字展厅、预约参观、河洛文创、内容管理”，右侧为主题切换、EN、账户入口。导航是低透明深墨玻璃，细边、轻高光、6-8px 小圆角，当前项仅用细古铜金线或文字提亮，不使用粗胶囊。
5. 复用三层博物馆玻璃：light 为通透月白青玉工作面，dark 为通透深墨玉信息面，compact 为紧凑筛选/输入/次按钮。玻璃能隐约感知背景，但文字始终清晰；禁止大面积高饱和绿和厚重不透明绿色卡片。
6. 卡片复用首页策展卡语言：真实文物或商品图片是主角，编号 01/02/03、细分隔线、小面积英文眉题、深墨玻璃文字层、细古铜/青玉描边；使用不对称编辑式编排，不做整齐等宽卡片墙。
7. 按钮至少 44px 高。主按钮为克制青绿实底或深墨底古铜描边，次按钮为细描边玻璃；圆角不超过 8px。按钮、卡片和输入框必须有 default、hover、focus、active、disabled、loading、error、success 状态。
8. 仅在大型首屏、馆藏索引、展厅索引、预约主区域和商城舞台复用稀疏点阵；表单、正文和后台不铺满点阵。桌面鼠标是 7px 月白青玉核心 + 46px 阻尼单圈，附近最多 5 个既有金点出现 4-7px 琥珀微光，不新增大量粒子。
9. 动效统一：页面进入为 opacity + 8px 位移，220-360ms；标题逐行揭示；卡片 hover 上浮 2px、图片放大约 1.02、边缘轻微鎏金；箭头右移 4px；按压 0.98；禁止弹跳、旋转炫技、霓虹呼吸和长时间自动动画。
10. 移动端使用 390 x 844 真实应用布局：顶部保留紧凑品牌与必要工具，底部固定五项导航“首页、馆藏、展厅、预约、文创”；任务摘要使用 Bottom Sheet；所有触控目标至少 44px，底栏不能遮住正文和主按钮。

【2026-08-11 调色补充锁】
11. 深色首页的高级感来自近黑、石墨、烟灰、暖象牙和真实材质的明度层次，不来自大面积青绿色。全局画布以近黑深墨（约 70% 以上画面）为主，次级环境使用炭黑/烟灰/深木色，卡片玻璃保持中性深墨；青玉绿只作为极少量交互光、点阵或当前状态，面积不超过 2%，不能把卡片或后台工作面染成绿色。暖象牙是标题和主要文字，古铜金只用于编号、细线、焦点和当前态，面积不超过 5%。允许自然青铜、木材、石材、宣纸灰和低饱和蓝绿反射，但整体不能有青绿滤镜、绿色平面或单一色调疲劳。

【全站真实功能边界】
保留这些页面和功能：首页、探索馆藏、文物详情、文化文章详情、数字展厅、3D 数字展项、预约参观、河洛文创、登录/注册/找回/重置密码、个人中心、内容管理、运营管理。不要增加真实支付、社交动态、会员等级、直播、AI 导游或新的业务模块。

【生成规则】
后续每次生成一张高保真 Web 应用效果图，无浏览器外壳、无电脑模型、无手机模型、无水印、无设计软件界面。使用准确简体中文，保留少量英文档案标签。参考图用于锁定材质、配色、字体层级、导航和卡片语言，不要机械复制首页三栏构图到所有页面。预约、商城、账户要像清晰的任务工作台；后台要紧凑可扫描，不能做成海报。

【统一避雷】
不要紫蓝渐变、霓虹赛博、纯黑大平面、满屏金色、宫廷红金、米黄古风、圆润胶囊、超大圆角、悬浮卡片套卡片、等宽功能卡阵列、玻璃过曝、强模糊、假 3D 图标、无意义数据图、随机文物、假 Logo、英文乱码、中文错位、文字压图、横向溢出。
```
