# 安卓快速试跑

本电脑已具备 Node、项目依赖和 ADB。连接一台安卓手机，允许 USB 调试，在手机 Chrome 打开 https://heluo.pocketbay.app/，保持解锁和前台；测试期间不要手动切换页面。

在仓库根目录 PowerShell 执行：

```powershell
cd frontend
node scripts/android-quick-check.mjs
```

末尾 REPORT 路径指向 HTML 汇总。将同目录 report.html、results.json 和 PNG 截图一起发给组长即可，不需要抄写 Word。首次在其他电脑需安装 Node、ADB 和本项目锁定依赖，此命令不是免安装工具。

范围：首页、馆藏、展厅、预约、文创、一个真实链接进入的3D详情；真实手机渲染、主内容、横向溢出、已完成加载的坏图、页面错误、3D running最终状态。失败返回非零退出码。

只浏览公开页面，不注册或提交预约订单。耗时是单次导航到 main 可见的观察值，3D另等待running，不是完整可操作耗时、LCP或性能基准。截图是手机网页视口，不含浏览器系统栏。网络类型和正式发布版本需运行者另记。

2026-09-11试跑：V2366HA、Android16、Chrome133；首轮隐藏桌面导航导致脚本超时，已改可见链接。第二轮33秒，五个普通页面基础检查通过，但3D截图显示连接中断；初版判定只等待首次running而误标通过，已补最终running断言。保留该截图作为待复核证据，不称完整3D功能通过。
