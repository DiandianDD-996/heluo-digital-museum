# 洛笙八人试用套件

2026-11-21 · 状态：**仅准备，尚未执行** · 适用：中文公众端导览（默认关闭，需候选构建）

> 这份文件是给人用的，不是给机器跑的。执行代理不得代填结果。
> 试用目的是拿信号，不是验收；人数少，结论只作方向判断。

## 1. 开始前

| 项 | 要求 |
| --- | --- |
| 环境 | 同一批受控候选；开跑前由负责人核对签核、产物、证据包与批准范围，并登记[放行记录](2026-11-19-luosheng-acceptance.md#unified-release-record)的批次和试用前凭证。旧六卡预检不替代本方案的至少 8 张双签及真实高频覆盖要求。未签或合成环境只计演练，不占 8 人名额 |
| 参与者 | 8 人，非本项目成员；尽量覆盖"常逛博物馆"和"很少逛"两类 |
| 时长 | 每人 10–15 分钟，单人独立完成，不提示、不纠正 |
| 记录 | 只记任务完成情况与观察，**不录屏、不收集原话、不记录个人信息** |
| 同意 | 开始前口头说明：会记录匿名完成情况与问题类别，不记录你的原话 |

## 2. 五个任务

按顺序给，不要提前透露"正确答案"。

| # | 交给参与者的话 | 成功标准 | 观察什么 |
| --- | --- | --- | --- |
| 1 | 「你只有五分钟，让它带你看一件东西。」 | 给出具体展品，并有一个可点的看点动作 | 是否又给四个入口；要几下才到达展品 |
| 2 | 「你不想预约，只想看看那件青铜鼎。」 | 不提预约，直达鼎 | 否定有没有被理解；有没有反复推荐预约 |
| 3 | 在侧视图问「另一只在哪」 | 承接当前看点，给出背视图 | 是否要求重新说展品名；澄清是否只问一次 |
| 4 | 接着说「我说的是脚」 | 改按三足回答，画面不自动切走 | 纠正是否生效；有没有打断当前观看 |
| 5 | 「先去预约页看看，再回来。」 | 回到原展品与原看点 | 是否失忆；回去要几步 |

## 3. 每人事后问三句（口头，不录音）

1. 哪一步让你觉得它在"装懂"？
2. 哪一步让你觉得它真的帮到你了？
3. 如果只能保留一个功能，你留哪个？

## 4. 记录表

用[结果模板](luosheng-eval/trial-results-template.md)。每人一行，任务栏填 `成功 / 部分 / 失败`，未执行填 `未测` 并说明原因；观察栏写事实不写评价。另填事件的分子与分母；没有实际尝试记「无样本」，不要记 100%。

## 5. 判读口径

| 指标 | 目标 | 不达标怎么办 |
| --- | --- | --- |
| 任务完成率 | ≥80% | 先看是哪一步断的，优先修意图与状态 |
| 同一歧义重复澄清 | 逐例应最多澄清 1 次；重复占比目标 ≤5% | 按歧义场景计数，不把换话题后的澄清算进原场景 |
| 动作到达率 | ≥95% | 检查按钮是否真的落到图版 |
| 返回成功率 | ≥90% | 检查跨页状态是否被清空 |
| 无依据断言 | 0（抽样 50 条） | 任何一条即停发，回到证据校验 |

样本不足 8 人时，标"样本不足"，不得声称达标。

### 另做 50 条回答盲审

用同一受控候选，审稿人用独立题号抽查 50 条**实际回答**，逐条和当轮卡号、修订、原句核对，记录通过／发现无依据断言／无法核验。放行记录只汇总题号、证据编号及判断，不在仓库复制访客问答。不用 40 个试用任务数充当 50 条回答，也不用合成回归充当正式盲审。未满 50 条、存在无法核验或发现无依据断言时不得标通过；有无依据断言即停止放行。

### 真实问法回灌须另行同意

主试用依然不留原话。若负责人另行批准采集，试用结束后单独邀请参与者自愿提交**由本人删去个人信息的问法**；单独说明会加入离线评测、谁能查看，可不参加且不影响本轮结果。未经明确同意不记录、不回溯日志。提交后先由人工核对隐私和是否确为参与者原本的问法，删除含身份、联系方式、订单等可识别信息的条目；离线材料只保存通过复核的问法及意图／预期，不关联试用编号、访次、Cookie 或答复正文。没有 20 条合格真实问法就留待补足，不用脚本编造。

## 6. 不许做的事

- 不提示参与者该问什么；
- 不在中途改代码；
- 不用"访客说它挺好的"替代任务完成情况；
- 不把这一轮结论写成"产品验收通过"。
