## 3. 常见问题与应对

| 游客问法 | 走哪条路 | 回答要点 |
| --- | --- | --- |
| 这是真的吗 / 是原器照片吗 | 来源卡 | 数字模型、网页渲染，不是照片 |
| 什么年代 | 断代卡 | 馆方记录的分期；出土地需另查 |
| 多大 / 多重 | 尺寸卡＋缺证 | 整体尺寸有记录；重量没有 |
| 哪里出土 | 缺证 | 记录为空，不能据此断定没有其他线索 |
| 只有两条腿，是不是缺了 | 三足卡 | 遮挡解释，不是缺损 |
| 纹样象征什么 | 纹样卡 | 没有已审寓意来源 |
| 什么颜色 | 渲染卡 | 光影来自渲染，不是锈色证据 |
| 怎么看 | 机位卡 | 固定机位对比，先确认机位 |
