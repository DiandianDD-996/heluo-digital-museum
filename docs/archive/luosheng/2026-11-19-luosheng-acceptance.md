## 本机体验正式全站导览

**查看已登记的八卡体验版：** 在仓库根目录运行 `./frontend/scripts/luosheng-local-demo.ps1`。脚本从当前代码构建到独立临时目录，核对冻结八卡后打印 `LUOSHENG_LOCAL_DEMO_URL`。地址仅在本机有效，默认保留 15 分钟；可用 `-Seconds 120` 缩短。传 `-Smoke` 则运行四组自动浏览器检查，结束后关闭，不留体验入口。不会覆写默认 `frontend/dist` 或改变部署配置；此处使用隔离预约夹具，不调用真实模型，也不计入真人试用。

### 分步启动与排查

关联 LS-02／LS-04／LS-08。在仓库的 `backend` 目录运行下列 PowerShell 命令（需要项目现有的 Maven、Node 和前端依赖）：

```powershell
$env:LUOSHENG_LOCAL_DEMO = '1'
mvn -B '-Dtest=GuideExhibitIntegrationTests#serveLocalCandidate' test
```

打开终端输出的 `LUOSHENG_LOCAL_DEMO_URL`。从首页点「洛笙导览」，问「我只有五分钟，带我看一件」，点「带我找鼎耳」，再用「接着问」试看年代、出处和缺证提示。可另问「明天还有三个人的名额吗？」体验公开时段。前端与后端均绑定本机回环、自动选择空闲端口，默认 15 分钟后退出；如需短时验证，可设置 `LUOSHENG_LOCAL_DEMO_SECONDS`（1–900 秒）。

这条路径使用正式组件和正式 API，资料及公开时段来自隔离测试库和合成卡，年代回答可能显示英文测试文字。没有真实模型、馆方正式证据、实际预约或公网部署；不计入正式试用。不要输入个人信息。下方旧模拟预览仍用于测试特定展签流程。

如要查看用户已登记通过的 2026-11-22 八卡受控候选，在运行前加设 `$env:LUOSHENG_LOCAL_DEMO_DATED = '1'`。测试先执行双签登记一致性检查，校验固定候选文件 SHA-256，只在测试临时目录写入批准指纹，不接触部署配置。可用「它是什么年代的？」和「在哪里出土？」对照原文及缺证。仅本机回环，仍使用隔离预约夹具，未设置真实模型地址或凭据；不计入正式试用。结束后移除本次设置的 PowerShell 环境变量即可恢复合成路径。

在上述两个演示开关之外再设置 `$env:LUOSHENG_LOCAL_DEMO_SMOKE = '1'`，同一 Maven 命令会自动用 Chromium 验证 1440px 浅色／390px 深色两条八卡路径，并在检查结束后关闭，不留体验入口。若使用本机 Chrome，可把 `$env:LUOSHENG_CHROME` 设为其可执行文件的绝对路径；否则使用 Playwright 已安装的 Chromium。要给人体验时不要设置 `LUOSHENG_LOCAL_DEMO_SMOKE`。

日期版只在同源讲解接口的八卡卡号、修订、原文、出处均与冻结包一致时打印入口。端口可能变化，不要复用上次的地址或其他测试实例的端口。

如要分步验证实际生产构建，把 `VITE_GUIDE_PRESET_ENABLED`、`VITE_GUIDE_SITE_ENABLED`、`VITE_GUIDE_TURNS_ENABLED` 在本次构建进程中设为 `true`，从仓库根执行 `pnpm --dir frontend exec vite build --outDir <新建的绝对临时目录>`；然后把 `LUOSHENG_DATED_DEMO_DIST` 指向该构建目录，并按上述日期版命令运行。服务会核对首页确实来自该构建，不覆盖默认 `dist`，也不改变部署开关。不要用此方式挂载正式实例或接真实模型。

指定构建目录时额外跑 1440px 深色和 390px 浅色，各档都核对页面真实主题。可把 `LUOSHENG_DATED_DEMO_CAPTURE` 设为已有的绝对截图目录；反向主题以不同文件名保存，不覆盖原两组。

同次验证仅回滚前端：另设 `LUOSHENG_DATED_DEMO_ROLLBACK_DIST` 为默认关闭向导的前端构建绝对目录。跑过开启态四组后，用同一隔离后端验证关闭态首页、搜索、藏品、展项和公开预约，不应出现导览界面或浏览器导览请求。此检查同时确认八卡仍可从后端接口读取：只回滚前端不等于撤销后端访问，需停用接口时应单独关闭后端能力。

日期版也可在不设置 `LUOSHENG_LOCAL_DEMO_SMOKE` 时使用 `LUOSHENG_DATED_DEMO_DIST`，直接体验同一开启态静态构建；仍先比对首页及八卡再打印回环地址。回滚产物参数只用于自动冒烟。桌面浅色冒烟另用隔离暂停文件验证：不刷新即可暂停问答，已审讲解仍可读，查时段只发 GET，移除暂停文件后主动追问恢复引用。不等于正式实例演练。

自动演练在 JUnit 临时目录模拟批准指纹不匹配：刷新后，公开藏品仍可阅读，但讲解接口返回空列表，页面不显示旧卡；恢复原指纹并刷新后才可重新打开原文。正式批准记录和卡包不会被写入。这不验证撤回时已打开页面能否在不刷新情况下自动移除已展示内容。

桌面浅色迟到回复演练在正常同源请求拿到真实三足回答后，延迟页面读取结果。关闭面板、切到鼎耳并重开后才放行，验证旧正文、引用和背视图动作不出现，且能正常提交新问题。只注入客户端延迟，不替代真实模型的取消或计费核验。

桌面浅色生成故障演练另起访次，保留实际冻结八卡与公开问答接口。用回环端点触发生成不可用，再触发隔离后端的每日额度耗尽；两轮均检查无正文、无图版动作、无旧引用。主动点「读当前讲解」回到鼎耳图版，焦点落在图版标题，无新问答请求。额度为测试夹具，不代表供应商用量。

桌面浅色浏览器断网时，问答请求发生传输失败并清除旧引用。「读当前讲解」仍可回焦并继续阅读已打开的同一鼎耳图版，不启用离线缓存，也不保证刷新或跨页后可读；恢复网络后主动追问重新取证。服务端明确返回讲解不可用时，同一动作读取结果后会清掉旧图版和正文。断网期间无法获知服务端撤回，不作为撤回推送验收。

同一打包版在浏览器侧模拟一轮问答传输不返回，等待应用自身截止信号，核对先显示核对进度、随后显示超时，无旧引用、无重试，仍可读当前图版。后端生成超时及繁忙另由合成 HTTP 夹具复验，不代表正式供应商响应或计费。

八卡自动演练覆盖五个试用任务的固定走法：五分钟推荐、拒绝预约只看鼎、在三足侧视图问「另一只在哪」再说「我说的是脚」、主动切到背视图、查看隔离预约时段后返回同一看点。展开的窄屏问答面板会盖住部分看点入口，切换到三足前可先收起面板。脚本检查原文与卡号／修订、两轮追问不自动切图、拒绝预约时不请求预约接口、查询日期与预约页所选日期一致，并核对返回时保持背视图。预约路径只读公开时段，不会提交预约。这不是人能否独立完成任务的实测。

需要保留实页效果时，在自动验收模式下把 `LUOSHENG_DATED_DEMO_CAPTURE` 设为一个本机输出目录的绝对路径，将得到鼎耳图版、桌面年代引用、窄屏出土地缺证三张 PNG。截图来自隔离实例；请勿把导出的候选画面用于公开发布，也不要把截图提交到仓库。

## 停用与恢复演练

仅在主管批准的隔离环境执行；记录环境、应用版本、卡包版本、开关变更时间和执行人编号。当前无生产操作入口，以下为验收步骤，不是现成的生产指令。

1. 开两个独立会话。A 取得三足回答和出处后发起一条可控慢请求；B 保持首次邀请未接受。记录开关前生成调用数，并检查馆藏搜索、藏品详情、3D 封面和预约时段的基线。
2. 暂停自由问答。在 A 尝试追问、在 B 主动开始并提问，均不得开启生成。确认旧出处和问答建议不再显示，已审签的当前展签仍可打开。释放慢请求，确认旧正文和引用不交付、不写入追问上下文；已经开始的上游请求须另核实是否已取消或计费，不根据界面状态推断。
3. 若问题涉及讲解素材或错误引用，关闭对应内容；若影响范围无法限定，停用整套向导。用当前会话和新会话确认不再出现失效的向导入口或媒体，馆藏、3D 和预约主路径仍可用。动态停用与未随构建发布是两项独立验收。
4. 恢复前先核查原因已解决、卡包仍获准、预算可用；恢复后仅在游客主动操作时启动，旧请求不得重新出现。不满足条件保持停用。留存每阶段的匿名状态、调用计数、浏览器路径与结果，不记录游客原话或访问凭据。

当前十一题各跑三轮，提交 33 条记录；轮次编号为 1、2、3。每轮重建独立环境；含 `previousCaseId` 的纹样追问须接在本轮实际且正确的定位回答之后，在同一会话内完成，不预置或手选纹样。U04 的 `isolated-structured-date-conflict` 使用同一展品、藏品和语言下同键不同值的两张合成卡，不能把它们放入正式卡包；该题与其余用例隔离。将内部答复的 `PLATE_PROVENANCE`、`DISPUTED_EVIDENCE` 分别记录为 `plate-provenance`、`disputed-evidence`；结果中看点为 null 表示答复不依赖看点，不意味着清空界面看点。U04 的严格复核使用游客实际看到的冲突提示，不使用空的 API 正文。对照、会话顺序和隔离环境由测试人员或回放记录核验，批量工具不从结果推断。无动作时也必须显式记录空数组，不能省略。普通模式只检查结构和覆盖率，失败返回非零状态并列出错误编号。版本跟随用例文件。

```powershell

```

先让参与者自行找到一处器物细节，用自己的话说明看到了什么，然后展示如何拒绝或结束讲解。不要先教按钮位置；记录在哪一步求助。少儿须有监护人同意，不录原声，不填写姓名或联系方式。成人与孩子协作标「协作」，不计孩子独立完成。

### 主持人执行顺序

1. **开场前核对环境。** 记录日期、候选构建、卡包版本、设备和主题。阶段 B 正式试用须使用内容与图版均已签核的受控候选版；没有审签时可由内部人员走查流程，记录为「演练」，不计入 8 人。阶段 C 还要核对模型批准、预算、数据处理范围和问答开关；任一条件未满足时跳过自由问答，基础试用仍须满足阶段 B 的审签条件。不把预设或模拟回答当作模型结果。每位参与者从新会话的同一藏品入口开始。
2. **任务一：看懂器物。** 念「请从这件青铜鼎上找一个你感兴趣的细节，等会儿用自己的话告诉我，你看到了什么。」只记录是否能指出所在位置并描述一项可由已审签图文核实的观察，记录摘要即可；不要求说术语，也不按是否点过洛笙给分。参与者卡住时先问「你现在想做什么？」；如需具体提示，记录是在找入口、选看点、看图还是理解讲解时提供的。
3. **任务二：自主结束。** 念「如果接下来想自己逛，请把页面调到你希望的状态。」按实际分支记录「拒绝」或「结束」；验证洛笙未擅自讲话、切图或在同一会话重新邀请。不要为了让参与者完成任务而指着按钮念名称。
4. **可选任务：用自己的话追问。** 阶段 C 获批且参与者同意后，另起会话。念「像跟人逛展一样，接着问一个你还好奇的问题；觉得有疑问，也可以问它凭什么这么说。」不念预设样例。只记录意图类别与结果：接对看点、合理澄清、答错看点、无依据结论、出处对应、无公开出处时说清边界；模型失败则另记能否回到当前讲解。对照应由主持人看页面和已审签资料复核；不留游客原话，不把任务成绩加到基础 6/8。
5. **当场停止条件。** 若发现未经同意的语音或动作、跨会话带入内容、未审签资料外露，或把无依据的年代、出土地、寓意当成事实，停止对应能力的试用，记录缺陷编号、匿名步骤和版本；不要为凑够人数继续使用同一候选版。参与者可以随时退出，未完成记「未测」并注明原因类别。

基础判分：同一人两项均完成才算完成。未获得操作提示记「独立」；另一人明确协助操作记「协作」，不计入独立通过人数；主持人给出具体解法后才完成记「需提示」。8 人均有有效记录后，按独立完成至少 6/8 判读，并另外报告协作完成数、需提示数与未测数。未满 8 人不宣布达标，也不擅自改变分母。

## 一体化向导 · 从首页开始的联合试用

这张表用于判定同一位首次来访者能否从首页找到想看的细节，用自己的话连续追问，再根据图版或图注说明自己看懂了什么。上方展签试用从藏品详情开始，有自己的成绩。首批内部人员可用本表演练，8 位首次使用者的正式记录取自同一获准候选版本。[一体化向导方案](2026-11-21-luosheng-unified-visitor-guide.md)

### 主持人可以直接照读的任务

1. 记录候选构建、内容签核版本、模型与提示词版本、试用日期。给每位参与者一个新会话，打开普通中文首页。手机与桌面均安排试用，记录实际使用的设备、辅助技术和网络条件。记录使用匿名编号和意图摘要，参与者可以随时结束。
2. 念「你有五分钟逛这座博物馆。找一个你想看清的细节，用自己的话问问洛笙。看到它的回答或图以后，再问一句你自己还想弄明白的。最后，指给我看或告诉我，你从哪里看出来的？」让参与者决定选什么、怎么说、是否看图。给使用读屏的人同样的任务，可用图注定位、口述观察。
3. 观察参与者能否发现输入框，亲自输入第一问，看完继续问，并在同一会话找到依据。澄清时让参与者自己回答。若卡住，先问「你现在想做什么？」如需指出入口、教按钮或代操作，记下介入时机和原因。若先选到仅支持公开摘要的藏品，记录洛笙如何说明可问范围，以及参与者能否自己找到可细看的内容。
4. 核心任务完成后，另念「看看明天有没有适合三个人的参观时段，然后回到刚才那个细节」。记录实际日期、时段查询结果和是否回到同件同处。此项单列，便于定位从讲展品切到办事时的断点。

统一入口的合成回归脚本另输出 `Candidate guide UI timing`。各条记录只含视口、主题、能力类别和毫秒值：`public-search` 是公开搜索；`reviewed-answer` 是固定答复及对应依据入口（确认卡在折叠区就绪）；`slots-fixture` 是拦截的时段响应，`slots-seeded-api` 则来自隔离库的同源响应。计时从真实表单提交事件到 Playwright 检查通过，含脚本观察开销，不是纯渲染耗时。每种能力的样本量单独计，少量基线不报正式 P95；`realModelSamples: 0` 不计入获准模型的延迟或质量门禁。不要向正式入口运行会注入故障的合成回归脚本。
